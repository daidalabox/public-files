使った覚えがなくても、PHPは動いている。経営者・事務長・総務の担当者向けに、見つけ方と業者への聞き方をまとめました。

2026年10月21日、PHPという仕組みに見つかった重大な欠陥「PHP2Shell」の修正版が出ました。ログインしなくても、外からサーバーを乗っ取られるおそれがあるものです。

「うちはPHPなんて使っていない」と思った方ほど、注意が必要です。PHPは、会社のホームページから機器の設定画面まで、気づかないところで動いています。この記事は、システムを業者に任せている方に向けて、PHPがどこにあるかを確かめる手順と、業者に聞くことをまとめたものです。技術的な対応の詳細は、技術者向けの別の記事にまとめています。

この記事でわかること

  • PHPは、Webサイトの多くを裏で動かしている「エンジン」のような仕組み
  • 会社のホームページだけでなく、問い合わせフォームや社内のツール、機器の画面にも入っている
  • 自分で直す必要はない。自分で確かめる5つの方法と、業者に聞く3つの質問を押さえればよい

PHPとは何か、なぜ今さわがれているのか

PHPは、Webサイトや管理画面を裏で動かす仕組みです。車にたとえると、外から見える車体ではなく、中のエンジンにあたります。

調査会社の集計では、使っている言語が分かるWebサイトのうち、約7割がPHPで動いています。それだけ広く使われている仕組みに、今回の欠陥が見つかりました。

すでに攻撃も始まっています。大手のクラウド事業者は、公表の前から攻撃の試みを観測し、修正版が出た後には「広く悪用されている」と発表しました。攻撃の方法を示すプログラムも、ネット上に出回っています。

意外なところに入っているPHP

PHPは、次のような場所で動いていることがあります。

外から見えるものでは、会社や施設のホームページ、求人ページ、ブログがあります。問い合わせや予約のフォーム、ネットショップの注文画面も、裏でPHPが動いていることが多い場所です。

社内で使うものでは、ブラウザで開くファイル共有やWebメール、研修や顧客管理のツールがあります。

気づきにくいのは、ルーターなどネットワーク機器の設定画面と、昔のキャンペーンや旧サイトのように、作ったまま放置しているページです。

なぜ「使っている覚えがない」のか

理由は単純で、PHPを入れたのが社内の人ではないからです。ホームページは制作会社が、機器は保守業者やメーカーが用意しています。社内には、何で動いているかを知っている人がいないことが多いのです。

もう1つの落とし穴は、「サイトは最新にしている」という安心です。今回の欠陥は、サイトの中身ではなくエンジン側(PHPそのもの)にあります。サイトの中身を更新しても、PHPを更新しなければ直りません。

PHPが使われているか、自分で確かめる5つの方法

まずは、自分の会社のWebサイトで確かめてみましょう。上の方法ほど簡単です。

1. アドレスを見る
1. 会社のホームページを開き、お問い合わせや予約のページにも移ってみる
2. 画面上のアドレス欄を見る
3. アドレスの中に「.php」があれば、PHPで動いている手掛かりになります。ただし、表示されていないからといってPHPを使っていないとは限りません

2. ページのソースを見る(WordPressかどうか)
1. パソコンのブラウザでホームページを開く
2. 画面の何もないところで右クリックし、「ページのソースを表示」を選ぶ
3. キーボードの Ctrl と F を同時に押し、「wp-content」と入れて検索する
4. 見つかれば、WordPressで作られたサイトです。WordPressはPHPで動いています

3. ブラウザの開発者ツールで見る(Chrome・Edge)
1. ホームページを開いた状態で、キーボードの F12 を押す
2. 開いた画面の上の方にある「ネットワーク」を選ぶ
3. F5 を押してページを読み込み直す
4. 一覧の一番上の行をクリックし、「ヘッダー」の中の「レスポンス ヘッダー」を見る
5. 「X-Powered-By」の欄に「PHP」とあれば、PHPで動いている手掛かりになります。ただし、このヘッダーは非表示にできるため、見当たらなくてもPHP不使用とは判断できません。表示されたバージョンが実際のサーバー構成と一致するかも管理者に確認してください

4. WordPressの管理画面で見る(管理者の方)
1. WordPressの管理画面にログインする
2. 左のメニューの「ツール」から「サイトヘルス」を開く
3. 「情報」を選び、「サーバー」を開く
4. 「PHPのバージョン」の欄を見る

5. レンタルサーバーの管理画面で見る
1. ホームページを置いているレンタルサーバーの管理画面にログインする
2. 「PHPのバージョン」「PHP設定」などのメニューを開く
3. 設定されているバージョンを確かめる

バージョンが分かったら、修正版と比べます。修正版は 8.5.12、8.4.27、8.3.36、8.2.35 です。同じ系列で、この数字より古ければ対象です。8.1以下は公式の修正版が出ないため、新しい版への切り替えが必要になります。

機器の設定画面や社内のツールも、開いたときのアドレス欄に「.php」が出ていないか見てください。メーカーのお知らせのページで「PHP2Shell」と検索するのも有効です。

ただし、どの方法でも見つからなかったからといって、「PHPがない」とは言い切れません。PHPを使っていることを、わざと表に出さない設定がよく使われているからです。最後は、業者に聞くのが確実です。

業者に聞く、3つの質問

自分でPHPを直す必要はありません。ホームページの制作会社、サーバーや機器の保守業者に、次の3つを聞けば十分です。

1. PHPを使っていますか(ホームページ・ツール・機器のそれぞれについて)
2. 修正版に更新しましたか(更新した後、再起動まで済んでいますか)
3. 古くて更新できないものは、どうしますか(外から見えないようにするなどの対策はありますか)

メールなら、次のように送れば伝わります。

PHPの重大な脆弱性(PHP2Shell、CVE-2026-109618・109619)について、確認させてください。弊社のホームページと、御社で保守いただいているシステムで、PHPを使っているものはありますか。使っている場合、修正版への更新と再起動は済んでいますか。更新が難しいものがあれば、対策を教えてください。

レンタルサーバーで自分で管理している場合は、事業者のお知らせを確認し、管理画面でPHPを修正版か新しい版に切り替えます。切り替えると表示が崩れることがあるため、事前にバックアップを取ってください。

誰が担当しているか分からないものが見つかったら、まずは外から見えないように止められないかを相談してください。

今回で終わらせないために

今回洗い出したものは、そのまま「システムの台帳」として残しておきましょう。何が、どこで、どの業者の担当で動いているかの一覧です。

欠陥は、これからも必ず見つかります。台帳があれば、次は一覧を見て、業者に聞くだけで済みます。

まとめ

  • PHPは、ホームページから問い合わせフォーム、社内のツール、機器の画面まで、意外なところで動いている
  • 自分で確かめる方法は5つ。ただし、見つからなくても「ない」とは言い切れないので、最後は業者に聞く
  • 聞くのは「使っているか・更新したか・古いものはどうするか」の3つ。あなたの会社には、PHPがいくつありますか

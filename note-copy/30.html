連載「聞くAIから任せるAIへ」の番外として、事務処理編をお届けします。

月曜の朝。受信箱を開くと、返信が必要なメールが、どうでもいい通知の間に埋もれています。会議の資料はまだ途中、請求書は手元に積まれたまま。気づけば、仕事を始める前に、仕事を探す時間が過ぎている。

事務の仕事の重さは、一つひとつの作業ではなく、この「探す」「揃える」「見落とさないか心配する」にあります。先に動くAIは、まさにそこを引き受けようとする道具です。

連載ではここまで、先に動くAIが仕事のやり方をどう変えるかを見てきました。この番外は、毎日の事務の仕事だけに絞ります。メール、会議、請求書、契約、月次報告まで、12の業務を一つずつ並べ、今のやり方が、先に動くAIでどう変わるかを見ていきます。

この記事でわかること

  • 事務の仕事は、「用意する作業」と「確定する行為」に分けられる。AIが得意なのは前者
  • 毎朝・毎日の繰り返しと、期限や抜け漏れの確認は、先に動くAIと相性がよい
  • 最初は、下書きや一覧で終わる業務から始め、確定は人が行う

事務の仕事は、2つに分けて考える

事務の仕事には、2種類の作業が混ざっています。

  • 用意する作業: 読む、集める、分類する、照合する、下書きを作る
  • 確定する行為: 送る、払う、署名する、決める

先に動くAIが得意なのは、前者です。後者も製品によっては実行できますが、ここでは人が確認・確定する運用を勧めます。

この線を引くだけで、迷いが減ります。「この業務はAIに任せていいのか」と悩む代わりに、「この業務の、どこまでが用意で、どこからが確定か」と問えばよいからです。

たとえば請求書の処理なら、読み取って、照合して、おかしな点を拾い出すところまでが用意。振り込みのボタンを押すところが確定です。用意が速くなれば、確定する人の仕事は、確認と判断に集中できます。

12の業務で、今のやり方はこう変わる

一般的な事務の業務を12に整理し、頻度の目安をつけました。左が今のやり方、右が先に動くAIと進めた場合の姿です。

前半は、メール処理、スケジュール管理、議事録、資料作成、書類整理、請求書処理です。毎朝・毎日の確認が多く、「抜け」と「選別」に手間がかかる業務が並びます。

後半は、経費精算、見積比較・購買、顧客・取引先対応、契約事務、採用・入退職事務、月次報告です。期限の管理や、書類・条件の比較に手間がかかる業務が中心です。

Duetの公式の例にあるのは、メールの確認、未払いの請求の確認と督促文の下書き、給与計算、契約書の署名依頼などです。ほかの業務は、同じ型のAIで広がると筆者が考える使い方です。ここから先は、12の業務を一つずつ、もう少し細かく見ていきます。

前半6業務：毎朝・毎日の「探す」を減らす

# メール処理(毎朝・随時)
今のやり方は、受信箱を上から順に開き、返信が要るものを自分で選び、文面を考えて返す、というものです。大事なメールが、数が多い日ほど埋もれます。

先に動くAIと進める場合は、重要な案件の抽出と要約、返信の下書きまでを、朝までに用意してもらいます。送信は、自分で読んでから押します。

向いているのは、メールの量が多く、返信が遅れがちな人です。抜けを減らす効果は大きい一方、宛先や言い回しの確認は人の仕事のままです。

# スケジュール管理(毎朝)
今のやり方は、予定表を見て、会議の準備を思い出し、日程の重なりに気づいたら調整する、というものです。重なりに気づくのが当日になることもあります。

AIは、会議の準備、予定の矛盾、期限の確認を、毎朝まとめて並べる役です。「今日は何が危ないか」を、先に一覧で見せてもらえます。

日程の変更や相手への連絡は、確定する行為なので、人が行います。

# 議事録(会議後)
今のやり方は、メモを見返しながら、決まったこと、担当者、期限を書き出す、というものです。会議の直後は、まだ記憶が新しいのに、書く時間が取れません。

AIは、決定事項、担当者、期限の抽出を行い、一覧にしてくれます。会議のあとに、そのまま確認できる形で届くのが理想です。

ただし、内容の確定は人が行います。「誰がいつまでに」という約束は、記録としてそのまま残るため、人が一度読んで確かめます。

# 資料作成(随時)
今のやり方は、白紙の状態から文案を考え、報告書、表、スライドを組み立てる、というものです。最初の一行が出ない時間が、意外と長くかかります。

AIには、文案、報告書、表、スライドの下書きを作ってもらいます。たたき台があるだけで、仕事は「書く」から「直す」に変わります。

この業務は、必要なときに自分で頼んでも、手間は大きく変わりません。先に動くAIを使う理由は薄く、通常のチャットで足りる、というのが筆者の見立てです。

# 書類整理(毎日・週次)
今のやり方は、届いた書類を種類ごとに分け、ファイル名を付け、足りない書類がないかを探す、というものです。整理は後回しになり、探す段になって困ります。

AIは、分類、ファイル名の提案、抜け漏れの確認を行います。毎日、または週に一度、決まった時間にまとめて整えてくれる形が合います。

ファイルの削除や、保管場所の最終的な決定は、人が行います。

# 請求書処理(月次・随時)
今のやり方は、届いた請求書を読み、発注や金額と照合し、おかしな点を探す、というものです。月末に集中して、手が止まりがちな業務です。

AIは、読み取り、照合、例外の抽出を行います。「いつもと違う請求」だけを先に見せてもらえれば、確認の時間が絞れます。

Duetの公式の例にも、未払いの請求の確認と、督促文の下書きが挙がっています。支払いは確定する行為なので、人が元の書類と見比べてから行います。

後半6業務：期限と比較の「抜け」を拾う

# 経費精算(随時)
今のやり方は、領収書を集め、項目ごとに整理して、申請書を作る、というものです。

AIは、領収書の整理と、申請の下書きを作ります。ただし、発生の都度の業務なので、通常のチャットで足りることが多い、という見立てです。申請の送信は、人が行います。

# 見積比較・購買(購入の都度)
今のやり方は、複数の見積書を並べ、価格、納期、条件を見比べる、というものです。条件の細かい違いは、見落としやすい部分です。

AIは、価格、納期、条件を表に並べて比べます。見比べる手間が減り、「この条件だけ違う」に気づきやすくなります。

購入の判断と発注は、人が行います。これも発生の都度の業務で、通常のチャットで足りる側です。

# 顧客・取引先対応(毎日)
今のやり方は、届いた問い合わせを種類で分け、回答を考え、返事が来ない相手に催促を出す、というものです。

AIは、問い合わせの分類、回答の下書き、催促文の作成を行います。毎日発生する業務なので、先に動くAIの価値が出やすい領域です。

Duetの公式の例には、顧客管理の取引履歴を使ったフォローメールの下書きもあります。相手に届く文面は、人が必ず読んでから送ります。

# 契約事務(月次・随時)
今のやり方は、契約書を見比べて違いを探し、更新の時期を台帳で確認する、というものです。更新の期限を見落とすと、困るのは自分です。

AIは、契約書の比較と、更新期限の抽出を行います。「そろそろ期限が来る契約」を、先に知らせてもらえるのは、この業務の大きな利点です。

署名の依頼は、公式の例にもあります。署名は確定する行為なので、承認を人が行います。

# 採用・入退職事務(発生の都度)
今のやり方は、必要な書類、本人への連絡、進捗を、一件ずつ管理する、というものです。件数は少なくても、抜けると影響が大きい業務です。

AIは、必要書類、連絡、進捗の整理を手伝います。発生の都度の業務で、通常のチャットで足りることが多い側です。

個人に関わる情報が多いため、入れる情報の範囲を、先に決めてから使います。

# 月次報告(頻度の記載なし)
今のやり方は、実績を集計し、前月との違いを探し、説明の文章を書く、というものです。

AIは、実績の集計と、変化点・課題の説明の下書きを作ります。元の整理に頻度の記載がないため、図では空欄にしています。

数字は、元の表と照らして、人が確かめます。説明の文章が整って見えても、数字が合っているとは限らないからです。

先に動くAIが向く業務、チャットで足りる業務

12の業務を頻度で見ると、向き不向きが分かれます。これは筆者の見立てです。

  • 先に動くAIが向く: 毎朝・毎日・週次の業務(メール処理、スケジュール管理、書類整理、顧客・取引先対応)。決まった時間に、AIが先に用意してくれる価値が大きい
  • 通常のチャットで足りる: 随時・発生の都度の業務(資料作成、経費精算、見積比較、採用・入退職事務)。必要なときに自分で頼んでも、手間は大きく変わらない

先に動くAIは、数時間ごとに確認する仕組みです。急ぎの対応や、その場の判断には向きません。

「全部を任せよう」とすると、設定ばかりが増えて疲れます。毎日の繰り返しにだけ、先に動くAIを当てる。残りは、必要なときに通常のチャットで頼む。この割り切りが、続けやすい使い方です。

最初に任せる3つの業務

どれから始めるかは、次の3つが選びやすい業務です。

  1. メール処理: 重要案件の抽出、要約、返信の下書き。送信は自分で行う
  2. 議事録: 決定事項・担当者・期限の抽出。内容の確定は人が行う
  3. 月次報告: 実績の集計と、変化点・課題の説明の下書き。数字は元の表と照らして確かめる

どれも、結果が下書きや一覧で終わり、間違えても確定の前に止められます。まず1つの業務で5件ほど試し、直しの量を見てから広げます。

# 5件の試し方
筆者の提案として、次の手順をすすめます。

  1. 1つの業務だけを選ぶ。複数を同時に始めない
  2. 同じ業務を、5件ほど続けて任せる
  3. 毎回、AIの出した下書きと、自分が直した結果の差を見る
  4. 直しが減ってきたら、同じ型で次の業務に広げる
  5. 直しが減らないなら、その業務は、まだ任せない

「直しの量」が、任せてよいかの目安です。AIの出来を信じるのではなく、自分の直しの量で決める、という考え方です。

請求書・契約書・個人情報を扱う前に

お金や契約に関わる業務ほど、任せる前に決めておくことがあります。

  • 承認: 送信・支払い・署名・削除は、人が押す。Duetの公式の説明も、この4つの前に承認を待つとしています
  • 機密: 取引先の名前や金額など、入れてよい情報の範囲を先に決める。Geminiの公式の説明は、機密性の高い作業を避けるよう求めています
  • 記憶と削除: 連携を解除しても、過去に得た情報の記憶が残る製品があります。退職や契約の終了のときは、削除の手順まで確認します
  • 照合: 請求書の読み取りや契約書の比較は、元の書類と合っているかを人が確かめる

「便利だから」と、ここを飛ばすのが一番危険です。AIの下書きは速く、きれいに見えるぶん、確認を省きたくなります。確認は、速さの代わりに人が払う費用だと考えると、省かずに済みます。

# 始める前のチェック欄

  • ☐ 任せる業務を1つに決めた
  • ☐ その業務の、用意する作業と確定する行為を分けた
  • ☐ 確定する行為は、人が行うと決めた
  • ☐ AIに入れてよい情報の範囲を決めた
  • ☐ 試す件数(5件ほど)と、直しの量を見る日を決めた
  • ☐ 退職や契約終了のときの、削除の手順を確認した

まとめ

  • 事務の仕事は、用意する作業と確定する行為に分けて考える。AIが得意なのは用意する作業
  • 毎朝・毎日の業務は、先に動くAIと相性がよい。随時の業務は、通常のチャットで足りることが多い
  • 最初は、メール処理・議事録・月次報告のような下書きで終わる業務から。あなたの事務で、最初に任せたいのはどれですか
  • この記事の12の業務の「先に動くAIと進めた場合の姿」は、実際に動かして確かめた結果ではありません。各社の公式の説明をもとにした、筆者の見立てです。まずは1つの業務で、小さく試してみてください。

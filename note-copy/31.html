月曜の朝、メールを開くと未読が何十通も並んでいる。今日返すべき3通を探すだけで、朝の30分が消えていく。こんな朝に覚えはありませんか。

もし、その探す作業を、出社する前にAIが済ませてくれていたら。あなたは、返信の中身を考える仕事から始められます。

連載「聞くAIから任せるAIへ」(全3回)の最終回です。第1回で、日本からはまだ使えないClaude Duetのような「任せるAI」を、私たちはどう仕事に入れるのか、という問いを立てました。最終回で、その答えを出します。

結論は、Duetを待たずに、下書きだけ任せるところから今日始めることです。始め方と、任せすぎないための注意を整理します。

この記事でわかること

  • 日本でも、「下書きだけ任せる」使い方は今日から始められる
  • 先回り型のAIは他社にもあるが、日本での条件は製品ごとに違う
  • 任せすぎないために、承認・機密・記憶など5つの注意点を先に決める

ここまでの2回で、何が分かったのか

最終回から読み始めた方のために、結論の土台を短く置いておきます。

第1回では、Duetが「先に動いて下準備をし、確定は人に任せる」AIであること、そして2026年10月23日時点で日本から使えないことを整理しました。

第2回では、社長・個人事業主・部長の仕事を業務別に並べました。変わるのは「用意する作業」で、「決める・約束する・確かめる」は人に残ります。

この連載の答えは、任せるのは用意、決めるのは人です。

この線を先に引けば、AIの種類が変わっても、同じ考え方で使えます。逆に言えば、この線が曖昧なままでは、どんなに優れたAIを入れても、どこまで任せてよいのか迷い続けることになります。

待つ必要はあるのか。今日から始める3つの段階

Duetが日本で使えるかどうかは、まだ分かりません。では、それまで何もせずに待つべきでしょうか。

私はそう考えません。準備と練習は、今日からでも始められるからです。段階は3つに分けて考えると、無理なく進められます。

なお、この3つの段階は、筆者の整理です。各社が推奨している順序ではありません。

# 段階1:通常のチャットAIに、下書きだけ頼む
最初の一歩は、普段使っているチャットAIです。メールや会議メモを自分で貼り付け、下書きや整理だけを頼みます。

この段階では、AIが新着を自動で取りに行くことはありません。送信も自分で行います。その分、失敗しても被害が小さく、効果も確かめやすい始め方です。

ここで身につけたいのは、操作のコツよりも「頼み方の型」です。何を材料にして、何を作ってほしいのか、何はしてはいけないのか。この3つを毎回はっきり伝える癖をつけておくと、先回り型のAIに移ったときも、そのまま役に立ちます。

先回り型のAIは、あなたが見ていない間に動きます。だからこそ、最初に頼み方の型を作っておくことが、あとで効いてきます。

# 段階2:日本で使える先回り型を、条件を確かめて試す
AIが自分で動き出す仕組みは、他社にも出ています。ただし、日本で使えるかどうかは、製品とプランで違います。

  • Gemini Task(旧Spark): 日本向けに、Google AI ProとUltraでの提供が2026年7月に発表されています。条件は個人のGoogleアカウントで、仕事用・学校用のアカウントでは現時点で使えません。時間やGmailの条件で動かせます。ただし、有効にできるスケジュールは50件、同時に動くタスクは15件までです。
  • ChatGPT dots: ProとBusiness Premiumで提供が始まり、Enterpriseは管理者が有効にするとベータで使えます。対象は一部の地域に限られ、公式ヘルプは日本を除外地域に含めていませんが、対象プラン・年齢・段階的展開の条件があります。契約中のアカウントで利用可否を確かめる必要があります。

どちらも、使える条件は変わりやすいものです。契約の前に、公式のヘルプで最新の条件を確認してください。

ここで気をつけたいのは、「使える」ことと「自分の仕事に向いている」ことは別だという点です。たとえばGemini Taskは、個人のGoogleアカウントが条件です。会社のアカウントで日々の仕事をしている方にとっては、そのままでは使えません。

試す場合は、仕事の本番データではなく、個人の予定や調べものなど、失っても困らないものから始めるのが安全です。

# 段階3:Duetが来る日に備えて、棚卸しをしておく
Duetが日本で使えるかどうかは、まだ分かりません。それでも、準備はできます。

  • 仕事を「用意する作業」と「決める作業」に分けて書き出す
  • 連携したいサービス(メール、予定表、会計)を整理する
  • 「送信・支払い・署名・削除は人が承認する」ルールを文章にしておく

この棚卸しは、AIを入れるかどうかに関係なく、仕事の見直しとして役に立ちます。書き出してみると、「自分しかできないと思っていた作業が、実は用意の作業だった」と気づくことがあります。

そして、承認のルールを先に文章にしておくと、新しいAIが来たときに「どこまで許すか」で迷いません。準備として、いちばん費用のかからない一手です。

最初に任せる仕事は、どう選ぶのか

最初の仕事選びで、多くの方がつまずきます。やる気のある方ほど、最初から大きな仕事を任せたくなるからです。

ここは逆に考えます。最初は、失敗しても困らない仕事を選びます。次の条件が多く当てはまるものから選んでください。

  • ☐ 間違えても、確定の前に人が止められる
  • ☐ 結果が、下書きや一覧で終わる(送信や支払いは含まない)
  • ☐ 週に何度も繰り返す
  • ☐ 元の資料と照らして、確かめられる
  • ☐ 個人情報や機密を入れなくて済む

筆者の整理では、メールの仕分け、議事録、社内向けの案内文、月次報告の下書きが始めやすい仕事です。

選び方のコツは、「失敗したときに誰が困るか」を想像することです。自分だけが少し手間をかけて直せば済む仕事は、練習に向いています。取引先に届いてしまう仕事は、最初には向いていません。

まず1つの業務で5件ほど試し、直しの量を見てから広げます。直しが多ければ、頼み方を変えるか、その仕事を任せる対象から外します。直しが少なければ、次の業務に広げます。この確かめ方は、実測の効果ではなく、一般的な小さく始める進め方です。

# そのまま使える指示文
次の指示文は、そのまま貼って使えます。取引先の名前などは、伏せてから貼ってください。

次のメールを、期限と重要度で分類して。今日返すべきものを最大5件挙げ、返信の下書きを作って。送信や削除はしないで。

この会議メモから、決定事項・検討中・担当・期限を表にして。メモにない情報は補わず、確認が必要な点を最後に質問として並べて。

この月次実績表から、前月との増減の要因の仮説と、確認すべき点を3段落で書いて。数字は元の表と一致させ、わからない点は「未確認」と書いて。

3つの指示文には、共通点があります。「何をしてはいけないか」を、必ず書いていることです。送信や削除はしない。メモにない情報は補わない。わからない点は「未確認」と書く。

AIに任せるときの安全は、この一言から始まります。

なお、これらの指示文は、筆者が一般的な事務の業務を想定して書いた例です。各製品での成功を検証したものではありません。自分の仕事に合わせて、言葉を直して使ってください。

立場によって、最初の一歩は変わる

同じ「下書きだけ任せる」でも、立場によって選ぶ仕事は変わります。第2回の整理に沿って、最初の一歩の例を置いておきます。これも筆者の提案です。

  • 社長: 判断の前の材料づくりから始めます。たとえば、月次の数字を読むための要点整理や、届いた依頼メールの優先順位づけです。判断そのものは、これまでどおり自分で行います。
  • 個人事業主: 事務の手間から始めます。たとえば、問い合わせへの返信の下書きや、予定の調整案の用意です。自分で全部をやっている分、用意の作業が減る効果を感じやすい立場です。
  • 部長: 報告と連絡から始めます。たとえば、会議メモの整理や、メンバー向けの案内文の下書きです。チームに関わる文章は、送る前に必ず自分の目を通します。

どの立場でも、共通する考え方は同じです。AIが用意し、人が決める。この順番は変えません。

任せすぎないための5つの注意

さて、ここからが最終回でいちばん大切な部分です。

任せる範囲を広げる前に、次の点を決めておきます。AIが便利であるほど、「ここまでは任せない」という線を先に引いておく必要があるからです。

# 1. 承認を飛ばさない
送信・支払い・署名・削除は人が押します。dotsの公式の説明でも、下書きを頼んだだけでは送信の承認にはなりません。

「下書きを頼んだのだから、そのまま送られても構わない」と考えたくなる場面があるかもしれません。しかし、確定の一押しは、人が行う。これが、任せるAIと付き合うときの基本です。

# 2. 外から来た文章の指示に従わせない
メールやWebページの中に、AIへの命令文が紛れていることがあります。Duetの公式の説明も、隠された指示への防御を設計に入れているとしています。それでも、見慣れない依頼は人が確認します。

AIは、文章を読んで動きます。そのため、読む文章の中に「この宛先に送れ」といった命令が混ざっていると、それに従ってしまう危険があります。防御の仕組みがあることと、危険がなくなることは別です。

# 3. 機密は入れない
Geminiの公式の説明は、サインイン情報や支払い情報を入力しないこと、機密性の高い作業は避けることを求めています。

便利さに慣れてくると、つい何でも貼り付けたくなります。入力してよいものと、してはいけないものを、最初に自分の言葉で決めておくと、迷いが減ります。

# 4. 記憶は消えない
Duetは、連携を解除しても、過去に得た情報の記憶が残ると説明しています。dotsも、接続を解除しただけでは取得済みの情報は削除されません。

つまり、「連携を切ったから安心」とは言えません。退職や契約の終了時は、削除の手順まで確認します。始める前に、やめるときの手順を調べておくことをおすすめします。

# 5. 動かない日がある
Geminiは、利用の上限や混雑で、予定したタスクが実行されないことがあるとしています。大事な締切は、AIの通知だけに頼りません。

「毎朝、必ず届く」と思い込むと、届かなかった日に気づけません。AIの仕事は、あくまで補助です。締切の管理は、これまでの手段も併用してください。

どの製品も、公式に「誤りを起こすことがある」と書いています。だからこそ、最後に見るのは人です。

導入前に、手元で確かめる10分チェック

ここまでの内容を、導入の前に確かめるチェックとして並べておきます。すべてに答えられたら、準備は十分です。

  • ☐ 最初に任せる仕事を1つ決めた
  • ☐ その仕事は、下書きや一覧で終わる
  • ☐ 送信・支払い・署名・削除は人が押すと決めた
  • ☐ 入力してよい情報と、いけない情報を決めた
  • ☐ やめるときの削除の手順を確かめた
  • ☐ 大事な締切は、AIの通知以外でも管理する
  • ☐ 契約するプランが、日本で使えるか公式のヘルプで確かめた

全部にチェックが入らなくても、焦る必要はありません。入らなかった項目が、あなたの次にやることです。

この連載を通して、いちばん伝えたかったこと

最後に、この連載を書いた理由を、少しだけ書かせてください。

「AIに仕事を任せる」と聞くと、人の仕事が奪われる話のように感じる方がいます。けれど、この連載で見てきたのは、少し違う景色です。

AIが減らしてくれるのは、探す、まとめる、下書きする、といった用意の作業です。残るのは、決める、約束する、確かめるという、責任を伴う仕事です。そして、その責任を持つのは、これからも人です。

だから、聞くAIから任せるAIへ進むときに、いちばん大切なのは、AIの性能を見極めることではありません。どこまでを任せ、どこからを自分の手に残すかを、自分で決めることです。

冒頭の月曜の朝に戻りましょう。未読の山から、今日返すべき3通を探してくれるのがAIなら、その3通にどう返すかを決めるのは、あなたです。この分担が見えていれば、新しいAIが来ても、慌てることはありません。

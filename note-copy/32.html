出張の手配、備品の購入、申込みフォームの入力。どれも一つひとつは小さいのに、気づけば一日の半分が、サイトとサイトの行き来で消えている。そんな経験は、ありませんか。

Duetと何が同じで、何が違うのか

まず、全体像から。Museは「聞かれたことに答える」より、「目標を聞いて、自分で進める」ことに重心があるAIです。この点は、Duetと同じです。

では、違いはどこにあるのか。出自と入口です。Duetは、仕事で使う文章や情報の扱いに強いClaudeの延長にあります。一方のMuseは、MetaがInstagramやWhatsAppなどで培った「日常の連絡の場」に近いところから出てきました。入口のひとつがWhatsAppであること。これが、いちばん分かりやすい表れです。

また、公式の発表の書き方にも違いがあります。Museの発表は、旅行の手配、車を高く売る、トレーニング計画を生活に合わせて調整する、といった暮らしの目標を例にしています。事務の仕事を前面に出したDuetとは、見せ方が少し違います。ただし後述のとおり、Metaは中小企業向けの展開も始めました。

Museは、何をしてくれるAIなのか

Museは、Metaが2026年9月8日に発表した、パーソナルAIエージェントです。公式の発表は、9月30日に更新されています。

公式の説明では、Museは次のようなAIです。

  • 質問に答えるだけでなく、実際に作業を行う
  • 予定の管理、日々のタスクやプロジェクトの代行、大きな目標を行動の計画に変えることを手伝う
  • 基盤のモデルは「Muse Spark」。Metaが現時点で最も高い性能だと説明するモデル
  • 専用の仮想マシン「Muse Secure VM」の中で動き、利用者がふだん使うアプリをまたいで作業する
  • 利用者との会話から学び、何が大事かを理解して、精度を高める
  • 利用者が、Museに与える権限の範囲を自分で決められる

「仮想マシン」とは、クラウド上に用意された、自分専用のコンピュータのことです。パソコンの中に、もう1台パソコンがあるようなものだとお考えください。AIはそのコンピュータの中で働くので、利用者本人のパソコンやスマートフォンの中身を、直接触るわけではありません。

この「別の場所で働く」という作りが、あとで出てくる安全の話の土台になります。

どう頼むのか：目標を話すと、計画から一緒に作る

難しい操作はありません。メッセージのやり取りに近い形です。専用のアプリでも、WhatsAppでも、人に頼むようにメッセージを送ります。パソコンの難しい設定や、専門の知識は前提にしていない、と公式は説明しています。

流れは、次のようになります。

  1. 利用者が目標を伝える(例：出張の手配をしたい、料金を下げたい)
  2. Museが、個別の計画を一緒に作り、時間や手持ちの条件を調整する
  3. その後は、Museが自分で作業を進める
  4. 状況が変わったとき、または確認が必要なときに、利用者のところへ戻ってくる

公式の説明にある作業の例は、次のとおりです。

  • メールの送信
  • 旅行の予約
  • ブラウザを開いて、フォームに入力する
  • 利用者の代わりに、交渉する
  • 大きな目標に向けた、計画づくり

成果の例としては、車をより高く売る、料金を下げる、生活の変化に合わせてトレーニング計画を組み直す、といったものが挙げられています。これらはあくまで公式の紹介する例で、実際の成功率や、どのくらい得をするのかは示されていません。

時間のかかる作業は、アプリを閉じたあとも続きます。ここが「聞くAI」との、決定的な違いです。

チャットのAIは、画面を開いている間だけ働きます。Museは、利用者が別の仕事をしている間も、裏で進めます。頼んだ人が会議に出ている間に、手配が進む。そういう働き方です。

安心の土台：作業する役と、見張る役を分ける

「勝手に動くAI」と聞いて、まず心配になるのは、安全ではないでしょうか。Museの安全の考え方は、動く場所の作り方に表れています。

# 専用の仮想マシン(Muse Secure VM)
利用者ごとに、専用のクラウド上のコンピュータが用意されます。ほかの利用者のエージェントからは、アクセスできないよう隔離されています。ここに、Muse本体と、つないだサービスのデータ、認証情報が入ります。

# 見張り役(Sentinel)
同じコンピュータの中に、Museとは別の、隔離されたAI「Sentinel(センチネル)」がいます。Museの動きがインターネットに出るには、Sentinelの承認が必要です。必要なときは、Sentinelが利用者に許可を求めます。

たとえるなら、作業する人(Muse)と、外に出す書類をチェックする人(Sentinel)を、あえて別にしてあるということです。作業する人がだまされた場合にも、別のチェック役が不適切な操作を検知・制限することを狙った仕組みです。ただし、すべての攻撃を防げる保証ではありません。

# パスワードと支払い情報
公式の説明では、Museはパスワードや支払い方法を直接見られません。利用者が共有した認証情報は、安全な保管の場所に入ります。Museは、中身を見ないまま、それを使ってログインできます。利用者がブラウザに自分で入力したパスワードも、Museからは見えません。

便利さの裏側：一度話したことを覚える

Museには、記憶の機能があります。利用者が一度話しただけの細かいことも覚えて、あとで活用します。頼まれていなくても、提案することがあります。

公式の例は、暮らしの場面です。たとえば、Instagramで保存したレシピ動画から買い物リストを作る。ホームパーティーのメニューを考える。招待状を送る前に、友人の食事の制限を踏まえる、といったものです。

事務の仕事に置き換えると、「この取引先には、午前中に連絡する」「請求書は月末締め」といった、あなたの仕事の決まりごとを、一度話せば覚えてくれる、ということです。便利な反面、何を覚えているかを、利用者が把握していることが大切になります。

この点について、公式は「覚えたことを、利用者が『忘れて』と指示して、個別に消せる」と説明しています。記憶は、便利さと管理の手間が表裏一体です。覚えてくれるのはありがたい。けれど、何を覚えているかが見えなければ、不安も残ります。使い始めたら、定期的に「何を覚えているか」を確かめる習慣をつけると安心です。

お金はどう守るのか：使い切りのカードで買う

Museは、購入もできます。となると、気になるのは支払いです。支払いは、Stripe(決済の会社)の「Link」というサービスを通じて行います。

仕組みは、次のとおりです。

  • Linkの「エージェント向けのウォレット」が、購入のたびに、1回だけ使えるカードを発行する
  • そのため、利用者の本物のカード情報は、Museにも、買い物先にも見えない
  • Museは、Linkの購入保護(破損・紛失の補償、値下げ時の補償、返品手数料のかからない返品、対象商品の返品保証)が適用される、最初のAIエージェントだと説明されている

買い物の支払いを今後広げる予定として、「Shop Pay」という支払い手段の追加が「近日対応」とされています。また、「1Password」に対応して、利用者がすでに持っているログイン情報を使えるようにすることも、「近日対応」です。いずれも予定で、時期は確定していません。

事務の仕事で言えば、備品の購入や、オンラインでの申込みの支払いが近い使い方です。ただし、公式の説明は個人の購入を中心にしていて、会社の経費の承認や、社員ごとの支払いのルールといった仕組みについては、記載が見つかりませんでした。

手綱は、利用者の手に：何を自分で決められるか

公式の説明にある安全の仕組みを、表にまとめます。

  • 承認(公式の説明:メールの送信や購入など、重要な操作の前に利用者に確認する)
  • 接続するアプリ(公式の説明:利用者が選ぶ。与える権限の範囲も、利用者が決める)
  • メールの権限(公式の説明:「読むだけ」か、「利用者の代わりに送信まで」かを選べる)
  • 作業の記録(公式の説明:Museがしたこと、これからする予定のことの全記録を、見られる)
  • 権限の変更・解除(公式の説明:いつでも、権限を変えたり、サービスとの接続を外したりできる)
  • 学習への利用(公式の説明:やり取りを、MetaのAIモデルの学習に使わないよう、設定で断れる)
  • 広告(公式の説明:会話や仮想マシンの中のデータは、Metaの広告のシステムには共有されない)
  • 記憶の削除(公式の説明:覚えたことを「忘れて」と指示して、個別に消せる)
  • 今後(今年後半の予定)(公式の説明:「Muse Confidential VM」。仮想マシン全体を、利用者だけが持つ鍵で暗号化し、Meta自身もアクセスできなくする)

特に注目したいのは、メールの権限を「読むだけ」と「送信まで」に分けられる点です。最初は「読むだけ」で始めて、慣れてから「送信まで」に広げる。段階を踏んで信頼を育てられる作りは、事務の現場にとって、大きな安心材料です。

とはいえ、手放しで安心とも言えません。確認が足りない点が、ひとつあります。たとえば、受信したメールの文面に、AIへの悪意ある指示が隠れていた場合に、AIがそれに従ってしまう「プロンプトインジェクション」と呼ばれる攻撃です。公式の発表ページには、この攻撃への具体的な対策の記述が、筆者の読んだ範囲では見つかりませんでした。見張り役のSentinelは、その対策のひとつだと考えられますが、効き目の程度は、この説明からは分かりません。

事務の仕事なら、どこまで任せられるか(筆者の見立て)

さて、ここからが本題です。公式の説明をふまえて、筆者が事務の仕事に当てはめて考えたものです。各社の推奨ではなく、実際に試した結果でもありません。

事務の仕事は、「用意する作業」(読む、集める、比べる、下書きを作る)と、「確定する行為」(送る、払う、署名する、決める)に分けて考えると整理しやすくなります。Museの公式の例を、この2つに分けると、次のようになります。

  • 出張・会食の手配(Museの公式の例との近さ:旅行の予約が近い、任せ方の目安:候補の作成まで任せ、予約の確定は自分で)
  • 備品・消耗品の購入(Museの公式の例との近さ:購入と使い切りカードが近い、任せ方の目安:購入先と金額の上限を決めて、承認は毎回自分で)
  • 申込み・届出のフォーム入力(Museの公式の例との近さ:フォームの入力が近い、任せ方の目安:入力までを任せ、送信前に自分で見る)
  • 取引先への連絡・日程調整(Museの公式の例との近さ:メールの送信が近い、任せ方の目安:下書きまで。最初はメールを「読むだけ」の権限で)
  • 料金の見直しの交渉(Museの公式の例との近さ:交渉の代行が近い、任せ方の目安:条件と上限を先に決め、合意は自分で)
  • 月次の数字のまとめ(Museの公式の例との近さ:公式の例に近いものがない、任せ方の目安:連携先と対応を確かめてから)
  • 契約書・請求書の確認(Museの公式の例との近さ:公式の例に近いものがない、任せ方の目安:現時点では向かない可能性が高い)

「出張や購入の手配」「フォームの入力」「連絡の下書き」は、公式の例に近く、Museが得意な領域に見えます。一方で、数字の集計や、契約書・請求書の確認のような、正確さが最優先の業務は、公式の説明に例がありません。その場合は、元の書類と突き合わせる手間が残ると考えておくのが安全です。

もうひとつ、見落としたくないのが「頻度」です。毎日、毎週繰り返す、決まった確認(受信箱の見回しや、請求の期限の確認)は、「先に動くAI」の価値が大きくなります。一方、年に数回しかない手配は、その都度チャットで頼んでも手間があまり変わりません。Museの強みが活きるのは、「頼む手間そのものが重い」業務、つまり、いくつものサイトやフォームを行き来する手配系の業務だと、筆者は見ています。

今日できる準備：導入前に決めておくこと

使えるようになってから慌てないために、いまのうちに決めておけることがあります。次の項目を、紙に書き出しておくと、導入の判断が速くなります。

# 任せる範囲

  • ☐ 最初に任せる業務を、1つに絞る(例：出張の手配)
  • ☐ その業務の「用意する作業」と「確定する行為」を分けて書く
  • ☐ 確定する行為(送信・購入・予約・契約)は、自分が押すと決める

# 入れてよい情報

  • ☐ 取引先の名前、金額、個人情報のうち、入れてよいものを決める
  • ☐ メールの権限は、最初は「読むだけ」にする
  • ☐ 機密性の高い情報や、社外に出せない資料は、つながない

# 金額の上限

  • ☐ 1回の購入の上限額を決める
  • ☐ 毎回、購入の承認を自分で行う
  • ☐ 月ごとに、作業の記録を見て、請求と突き合わせる

# 終わらせ方

  • ☐ 使うのをやめるときの、接続の解除の手順を確かめる
  • ☐ 覚えさせた内容を、「忘れて」で消す手順を確かめる
  • ☐ 担当者が替わるときに、権限を誰が引き継ぐかを決める

結局、誰に向いているのか

筆者の見立てでは、次のように分けられます。

  • 向く人: 出張や購入の手配を、自分の言葉で頼んで進めたい個人。仕事とプライベートの手配が混ざる、個人事業主。複数のサイトやフォームを行き来する作業が多い人
  • 慎重に確認する人: 会社の業務に入れたい人。日本での提供開始は発表済みですが、法人向けの条件やデータの扱い、各機能の利用可否を確認してからでも遅くありません
  • 今できる準備をする人: 任せる業務の洗い出しと、承認のルールづくりは、どの製品でも同じです。いま通常のチャットAIで、下書きの作成から試しておけば、任せる製品が決まったときの助走になります。焦って製品を選ぶより、任せ方を先に練習しておく。それが一番の近道です

まとめ

  • 手配を「メッセージ1通」で頼める時代が、近づいています。Museは、その一つの形です。要点は、次のとおりです。
  • Museは、専用の仮想マシンで動き、アプリを閉じても作業を続ける、Metaの個人向けAIエージェント。メール・手配・フォーム入力・購入・交渉が、公式の例
  • 安全は、見張り役(Sentinel)、メールの権限の選択、全作業の記録、「忘れて」での記憶の削除など、層で作られている。それでも、重要な操作の前の確認は、人に残る
  • 中小企業向けの展開も始まっているが、提供地域、料金、データの扱いは、発表から分からない部分が多い。2026年10月23日に日本での提供開始が発表された
  • 先に決めるのは、任せる範囲、入れてよい情報、金額の上限、終わらせ方の4つ。あなたの仕事で、最初に手配を任せたいのはどれですか

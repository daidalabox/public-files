請求書を、出し忘れていた。気づいたのは、相手から催促が来てからだった。

事務の仕事をしていれば、一度は覚えのある場面ではないでしょうか。では、気づく役を、AIが先に引き受けてくれたらどうでしょう。

そんな発想の道具が、OpenAIが2026年9月29日に発表した「dots(ドッツ)」です。連載「聞くAIから任せるAIへ」の番外として、今回はこのdotsを取り上げます。

本編では、質問に答えるだけの「聞くAI」から、自分で動いて仕事を進める「任せるAI」への変化を、Claude Duetで見てきました。dotsは、ChatGPTの中に住む「任せるAI」です。すでにChatGPTを仕事で使っている人にとっては、いちばん入りやすい入口になる可能性があります。ただし、利用できるかどうかは、地域に加えて契約プランと段階的な提供状況によります。期待と不安が半分ずつ、というのが正直なところです。

この記事では、OpenAIの公式の発表とヘルプ、そして報道をもとに、dotsとは何か、どう動くのか、事務の仕事にどう当てはまるのか、任せる前に何を決めておくべきかを、順番に整理します。

【2026年11月9日追記】公式ヘルプによれば、dotsは18歳以上のProユーザーへ対象地域で段階的に提供中です。Business Premiumにはワークスペースの対象条件があり、Enterprise・Edu・Healthcareでは11月4日〜18日の管理者プレビュー期間中、管理者が有効にした利用者が使用できます。欧州経済領域・スイス・英国は対象外で、日本の個別アカウントに提供済みかは、公式の地域説明だけでは断定できません。契約プランとアカウント画面を確認してください。 この記事は、OpenAIの公式発表とヘルプ、そして報道をもとに整理しています。公式の説明と、事務の仕事への当てはめは、書き分けています。当てはめの部分には「筆者の見立て」と添えています。

この記事でわかること

  • dotsは、専用のクラウドのコンピュータとブラウザで動き、4,000以上のアプリにつながる、常時稼働のAI。ChatGPT、Slack、Microsoft Teams、音声通話から頼める
  • 動いてよい操作と、確認が必要な操作を、ルールで決められる。待機中の調べものは「読むだけ」で、送信や編集はできない
  • ProとBusiness Premiumで提供され、最初の1つの追加料金はない。ただし、日本での提供は公式ページに記載がなく、先に確かめる必要がある

dotsは、何者なのか

dotsは、OpenAIが「常時稼働のエージェント」と呼ぶAIです。ChatGPTのProまたはBusiness Premiumのプランに、最初の1つが含まれます。

これまでのChatGPTは、利用者が質問を送るたびに、答えを返す形でした。いわば、呼ばれたら答える相手です。dotsは違います。目標を渡して、任せる形です。公式の説明では、dotsは自分専用の作業環境で動き、複数のことを並行して進め、フィードバックから利用者の好みや基準を学びます。頼まれていない作業の候補が、先に示されることもあるとされています。

# 話しかける場所

  • ChatGPT(パソコン、ウェブ、スマートフォン)
  • Slack
  • Microsoft Teams
  • 音声通話

ただし、SlackとTeamsで文字を使って頼む機能は、「近日対応」とされています。

もうひとつ、地味ですが大きな特徴があります。場所をまたいで、文脈が引き継がれることです。報道によれば、ChatGPTで始めた件を、Slackにいるチームに渡しても、最初から説明し直す必要がありません。dotsが、進み具合や確認したいことを、持ち主に送ってきます。

どう動くのか：専用のコンピュータと、待機中の調べもの

仕組みを知ると、どこまで任せてよいかが見えてきます。
# 専用のクラウドのコンピュータ
dotsは、それぞれ、自分専用のクラウド上のコンピュータとブラウザを持っています。利用者は、いつでもその作業の様子を開いて、確認できます。

「クラウド上のコンピュータ」とは、利用者の手元の機械ではなく、インターネットの向こうにある、自分専用のパソコンのようなものです。利用者のパソコンの電源を落としていても、dotsは動き続けられます。

# アプリとのつなぎ方

  • つないだアプリを使える
  • プラグインを通じて、4,000以上のアプリにつながる
  • 許可すれば、利用者のパソコンにも、つなげる

どのアプリにつながるかは、契約のプランと、アプリごとの対応によります。仕事で使っているメール、予定表、チャット、表計算などが対象に入っているかは、導入の前に確かめる必要があります。

# 待機中は「読むだけ」
ここが、いちばん大事な点かもしれません。dotsは、指示がないときも、自分から役に立つことを探します。これを、公式は「待機中の調べもの」のように扱っています。

このとき、dotsは、つないだアプリを「読み取り専用」で調べます。メッセージの送信、アプリの内容の編集、ブラウザやパソコンの操作は、できません。つまり、頼まれていない時間帯に、勝手に送ったり、書き換えたりすることはない設計です。「先に動く」と「勝手に動く」の間に、きちんと線が引かれています。

# 学び方
dotsは、フィードバックから、好みや基準を学びます。【2026年11月9日追記】公式のプライバシーFAQによると、dotsはChatGPTのメモリや直近の会話の文脈を参照でき、dotとの会話もChatGPT側のメモリに影響し得ます。また、dotの存続中は会話や連携アプリに由来する文脈を保持し得るとされています。具体的な設定・削除・共有範囲は、導入時に公式FAQと管理者設定を確認する必要があります。

実際の動き方：請求書の例

仕組みの話が続いたので、具体的な場面に移りましょう。報道で紹介されている例を、2つ挙げます。

ひとつ目は、早期のテスターの例です。ある人が、媒体への請求書を出し忘れていました。dotsがそれに気づき、請求書を用意しました。そして、送る前に、本人の承認を待ったとされています。

冒頭の、出し忘れの場面そのものです。これは、先に動くAIの、いちばん分かりやすい形です。「気づく」「用意する」ところまでを任せ、「送る」ところは人が押します。事務の仕事で言えば、「用意する作業」と「確定する行為」を分ける考え方そのものです。

ふたつ目は、OpenAI社内の例です。Slackに報告された不具合を、dotsがすぐに調べ始める。新しいデザインを、動くアプリに変える作業に使う、といったものです。これは、事務というより、開発の現場の例ですが、「報告が来たら、すぐ動く」という使い方が分かります。

どちらも、OpenAI自身や、早期の利用者の例です。一般の会社で、どのくらいうまくいくのかは、示されていません。

暴走させないために：承認と安全のしくみ

先に動くAIで、いちばん気になるのは安全です。公式の説明にある、しくみを整理します。

  • ルール(公式の説明:組み込みのルールで、自分だけで動く場合と、先に確認する場合を分ける)
  • カスタムルール(公式の説明:特定の操作を、「許可」「承認が必要」「禁止」に決められる)
  • 自動の確認(公式の説明:アカウントに影響する操作や、情報を共有する操作を、自動でチェックする)
  • 本人が行う作業(公式の説明:パスワードの変更のような重要な作業は、必ず本人が行う)
  • 監視(公式の説明:安全上の問題が見つかったら、作業を止められる)
  • パスワード(公式の説明:保存したパスワードを、AIに見せずに、ログインに使える)
  • アクティビティ画面(公式の説明:作業の進み具合を見て、途中で向きを変えられる)
  • データ(公式の説明:法人向け(Business、Enterprise、Edu)の内容は、既定ではモデルの改善に使われない。個人向けのプランは、使うかどうかを選べる)

もうひとつ、OpenAIのヘルプには、次の注意があります。

  • 下書きを頼んだだけでは、送信の承認にはならない。送るには、別に承認が必要
  • 接続を解除しても、すでに取得した情報は削除されない。削除するには、dotのリセットが必要

とくに2つ目は、事務の現場で見落としやすい点です。「接続を外したから安心」とは、言い切れません。担当者が替わったり、契約を終えたりしたときに、「接続を外した」だけでは、取引先の情報などが残るかもしれません。

また、OpenAI自身も、エージェントが「まだ間違えることがある」と認めています。大事な成果物は、利用者が確認するよう求めています。

その先の話：会社向けの「専門のdots」

ここまでは、個人が使う話でした。その先には、組織の話があります。個人の「最初の1つ」とは別に、組織向けの「専門のdots」が、プレビューの段階にあります。雇用主が、特定の1つの業務に限った、専用のIDと認証情報を持つdotsを用意できる、というものです。

報道では、調達の業務や、請求書の処理が、社内でテストされたと伝えられています。小さなパイロットの形で、OpenAIのエンジニアが、各エージェントの責任の範囲を決めるのを手伝う、とされています。

また、Microsoftが、自社のガバナンスとセキュリティの管理の仕組み(Agent 365)で、専門のdotsを扱えるよう、OpenAIと協力している、と伝えられています。

事務の仕事の目線で言えば、これは、「人」に与えている権限と同じように、「エージェント」にも、役割を決めて、IDを割り当てる、という考え方です。最初の1つを個人で使うより、先の段階の話ですが、将来、会社で本格的に使うなら、避けて通れない論点になりそうです。

事務の仕事なら、どう使えるか(筆者の見立て)

さて、本題です。公式のページには、事務の業務ごとの「得意なこと」の一覧は、ありません。確かめられたのは、仕組みです。

  • つないだアプリを読んで、状況を調べる
  • 専用のブラウザで、作業を進める
  • 経過をアクティビティ画面で見て、途中で向きを変えられる

そこから、筆者が事務の業務に当てはめて考えたのが、次の表です。公式の推奨ではありません。

  • 受信メールの確認・返信の下書き(dotsの仕組みとの相性:メールをプラグインでつなげば、読んで下書きまで、任せ方の目安:下書きまで。送信は自分で)
  • 請求書の出し忘れの確認(dotsの仕組みとの相性:報道の例が近い、任せ方の目安:気づいて用意するまで。送信は承認)
  • チャットで来た依頼の整理(dotsの仕組みとの相性:Slack・Teamsから頼める、任せ方の目安:依頼を拾って、担当と期限の案を作る)
  • 会議の準備資料の収集(dotsの仕組みとの相性:専用のブラウザとアプリの読み取り、任せ方の目安:集める作業まで。内容の判断は自分で)
  • 発注・購入の手続き(dotsの仕組みとの相性:専門のdotsの例にある、任せ方の目安:個人用では慎重に。権限と上限を決めてから)
  • 契約・法務の確認(dotsの仕組みとの相性:公式の例がない、任せ方の目安:現時点では、人の確認が必須)

ここでも、「頻度」が分かれ道になります。毎朝や毎週の決まった確認(受信箱の見回し、請求の期限、未回答の依頼の洗い出し)は、「先に動いてくれる」価値が高くなります。一方、年に数回の作業は、通常のチャットに、その都度頼むほうが、準備の手間がかかりません。

Duet・Muse・Gemini Taskと並べて

  • 作っている会社(ChatGPT dots:OpenAI、Claude Duet:Anthropic、Muse:Meta、Gemini Task:Google)
  • 入口(ChatGPT dots:ChatGPT、Slack、Teams、音声、Claude Duet:Claudeのアプリとウェブ、Muse:専用アプリ、WhatsApp、Gemini Task:Geminiの画面(Task))
  • 待機中の挙動(ChatGPT dots:つないだアプリを読むだけ、Claude Duet:受信箱などを見て、知らせる、Muse:利用者に戻って確認を取る、Gemini Task:条件(時間・出来事)で動く)
  • 色の強い場面(ChatGPT dots:アプリをまたぐ作業、チームでの連携、Claude Duet:メール、予定、請求の確認、Muse:手配、購入、フォーム入力、Gemini Task:Googleのアプリの整理)
  • 日本での提供(ChatGPT dots:公式ページに記載なし、Claude Duet:米国のみ、Muse:記載なし、Gemini Task:日本のProとUltraに提供(個人のアカウント))

dotsの特徴は、「すでにChatGPTを使っている」「社内でSlackやTeamsが共通の場になっている」という会社と、相性がよいことです。ChatGPTのプランに含まれる形なので、新しい契約を増やさずに、試しやすいという利点もあります。

気になる点：日本で使えるのか

先に言っておくと、はっきりしません。公式の発表では、ProとBusiness Premiumの、対象の市場で、順次提供されています。EnterpriseとEdu、医療機関向けのワークスペースは、管理者が有効にすると、ベータで使えます。

対象外の地域は、ヘルプによれば、欧州経済領域、スイス、英国です。日本は公式ヘルプに挙げられた対象外地域には含まれていません。ただし、順次提供中のため、日本の全アカウントで利用できるとは限りません。まずは、自分のChatGPTの画面と、OpenAIの公式のヘルプで、使えるかを確かめてください。

# 料金と上限

  • 最初の1つは、ProまたはBusiness Premiumに含まれ、追加料金はない
  • 発表から1か月は、上限が拡張される
  • 今後、dotsの追加や、速度・作業量の拡張が予定されているが、金額は公表されていない
  • dotsとの会話は、ChatGPTの利用上限に数えられない。CodexやChatGPT Workで動かした作業は、通常どおり数えられる
  • 具体的な回数の上限は、書かれていない

「1か月の拡張」が終わったあと、どのくらい使えるのかは、はっきりしません。仕事で使い続ける前提なら、この点は、契約前の最重要の確認事項です。

今日できる準備：導入前に決めておくこと

使えるか分からない段階でも、決めておけることはあります。
# 任せる範囲

  • ☐ 最初に任せる業務を、1つに絞る(例：受信メールの確認)
  • ☐ 「用意する作業」と「確定する行為」を、分けて書く
  • ☐ 確定する行為は、「承認が必要」のルールにする

# つなぐアプリ

  • ☐ 最初は、読み取りだけでよいアプリから、つなぐ
  • ☐ 取引先の個人情報や、機密の書類が入っているアプリは、つながない
  • ☐ パソコンへの接続は、最後に、必要な場合だけ許可する

# ルール

  • ☐ 「許可」「承認が必要」「禁止」の、3つに、操作を振り分ける
  • ☐ 送信・支払い・削除は、「承認が必要」か「禁止」にする
  • ☐ 週に1度、アクティビティを見て、意図しない動きがないか確かめる

# 終わらせ方

  • ☐ 接続を外したあとの、情報の削除の手順(dotのリセット)を確かめる
  • ☐ 担当者が替わるときに、権限と学習した内容を誰が引き継ぐか決める
  • ☐ 「1か月の拡張」が終わったあとの上限を、画面で確かめる

結局、誰に向いているのか

筆者の見立てでは、次のように分けられます。

  • 向く人: ChatGPTのProやBusiness Premiumを、すでに契約している人。社内のSlackやTeamsを使っていて、そこから頼みたい人。受信箱や請求の確認のような、毎日の見回しが負担の人
  • 確認が先の人: 日本で使えるか、プランが対象かが分からない人。まず画面と公式のヘルプで確かめます
  • まだ待つ人: 取引先の個人情報や、機密の書類を、そのまま扱わせたい人。データの扱いと、削除の手順が分かってからのほうが安全です

まとめ

  • 出し忘れに「気づく」役を、AIに任せる。dotsは、その入口になりうる道具です。要点は、次のとおりです。
  • dotsは、専用のクラウドのコンピュータとブラウザで動く、ChatGPTの常時稼働のAI。4,000以上のアプリにつながり、ChatGPT・Slack・Teams・音声から頼める
  • 待機中は読むだけ。動いてよい操作は、「許可」「承認が必要」「禁止」のルールで決められる。送信の前の承認は、下書きを頼んだだけでは足りない
  • 接続を解除しても、取得した情報は残る。削除には、dotのリセットが必要。日本での提供と、1か月後の上限は、公式ページから分からない。あなたの仕事で、最初につなぎたいアプリはどれですか

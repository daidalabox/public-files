そこで考えました。自分だけが使える画像生成ツールを、自分で持てないか。公開はしない。他人に使わせない。できれば、お金もかけたくない。

やってみたら、思ったよりずっと簡単に動きました。しかも無料枠の範囲で。

連載「Cloudflare Workers AI」の第2回、構築編です。前回のテスト編では、文字のチャットを手作業で立ち上げました。今回は、画像生成ツールを、ほぼ自動で作ります。この記事は、うまくいった部分だけを書きます。つまずいた話は、次の失敗とコスト編にまとめました。

この記事でわかること

  • 画像生成ツールの全体像と、各部品の役割(図つき)
  • Claudeにコネクタをつないで、Workerの作成からデプロイまで任せる進め方
  • 自分だけが入れる門(Cloudflare Access)のつけ方と、費用の考え方
  • 使いながら足した7つの機能と、実際のコードの抜粋

全体像：入口で守って、中で使い分ける

まず、できあがったものの全体像です。

登場する部品は4つです。

  1. スマホ・PC:ブラウザでツールを開く
  2. Cloudflare Access:入口の門。許可したメールアドレスの持ち主だけを通す
  3. Worker:画面と、AIへの窓口がひとつのファイルにまとまった小さなプログラム
  4. Workers AI:実際に画像を作るモデル。簡易用と高精度用の2つを使い分ける

認証(Access)を通った自分だけがWorkerに届き、Workerが簡易と高精度の2つのモデルを使い分けます。簡易は枚数を回す用、高精度は仕上げ用です。

使うモデルは、次の2つが中心です。

  • 簡易(モデル:FLUX.1 schnell、向いている使い方:ラフ案を何枚も回す。ステップ数は1〜8で選べる)
  • 高精度(モデル:FLUX.2 klein 9B、向いている使い方:ここぞという仕上げの1枚)

参考画像を渡すときなど、条件によってはほかのモデルに振り分けます。この振り分けで私がつまずいた話は、失敗とコスト編に書きました。

準備は、ほぼClaudeに任せた

最初に決めたのは、手を動かさないことでした。前回のテスト編では、ちまちまと手動で設定しました。今回は自動です。

CloudflareのコネクタをClaudeにつなぐと、Workerの作成からデプロイまで、Claudeが代わりにやってくれます。コードを貼って、保存して、デプロイして。あの地味な作業が、ほとんど要りません。

自分でやったのは、次の2つだけです。

  • コネクタを入れて、権限を許可する
  • ダッシュボードで Zero Trust を有効にする

# Claudeへの頼み方
頼み方は、特別なものではありません。たとえば、こんなふうに伝えます(書き方の一例です)。

Cloudflare Workers AI で、自分専用の画像生成ツールを作ってください。
・プロンプトを入れると画像が出る、スマホでも使える1画面
・簡易モードと高精度モードを切り替えられる
・使うのは無料枠の範囲で

大事なのは、最初から全部を言わないことです。まず「動く最小のもの」を作ってもらい、触ってみて、欲しいものを足していく。この進め方が、あとで書く7つの機能につながりました。

# コネクタは、つなぎっぱなしにしない
ひとつだけ、気をつけたことがあります。コネクタは、つなぎっぱなしにしないことです。Cloudflareの権限を持たせたままにするのはリスクが高いので、作業のときだけつないで、終わったら切る運用にしました。権限も、必要な範囲だけに絞っています。

コネクタには古い種類もありますが、いまは非推奨です。Cloudflare全体のAPIを扱える新しいほうを選びました。

公開はしない。入れるのは、自分だけの門をつくる

Workerは、URLさえ知られれば誰でも開けてしまいます。自分専用にしたいのに、それでは困ります。

そこで、Cloudflare Access(Zero Trust)で門をつけました。Accessの許可ポリシーで認められたメールアドレスにワンタイムコードを送る仕組みです。メールアドレスを入力しただけで通れるわけではなく、受信したコードによる認証を経てアクセスします。許可するのは、自分のアドレスだけにしています。

流れは、おおまかにこうです。メニューの名前は変わることがあるので、画面の表示に合わせて読み替えてください。

  1. ダッシュボードで Zero Trust を有効にする(最初の一度だけ)
  2. Accessで、保護したいアプリケーションとしてWorkerのアドレスを登録する
  3. 通す人のルールを作る。条件は「メールアドレスが、自分のものと一致する」
  4. ログイン方法に、ワンタイムコードを使う

登録が済むと、ツールのURLを開いたとき、最初にメールアドレスの入力画面が出ます。許可したアドレスを入れるとコードがメールで届き、それを入力すると、ようやくツールの画面が開きます。

気になるお金の話です。Zero Trust の Free プランは、50ユーザーまで0円です。自分ひとりなら、課金は発生しません。ここで述べるのはCloudflare Access側の契約の話です。Workers AIによる推論の消費量・モデルごとの支払要件とは別管理なので、画像生成を含めて絶対に0円になるという意味ではありません。プラン料金は公開時点の記録として扱い、契約時には公式料金表で再確認してください。

# 落とし穴がひとつありました
Workerの公開用サブドメインを変えた直後に、「このサイトへの接続はセキュリティで保護されていません」と出たのです。あれっと思いましたが、結論は、ただの反映待ちでした。数分おいたら、普通に開けました。

設定を変えた直後のエラーは、慌てずに少し待つ。これだけで済むことが多いです。

# Accessの考え方を、もう少し知りたい人へ
今回やったのは、「入口で、誰なのかを確かめてから通す」という、ゼロトラストの考え方のいちばん小さな実践です。社内ネットワークの中だから安全、という前提を置かず、毎回確かめる。自分ひとり用のツールでも、この考え方はそのまま使えます。基礎から整理して学びたい方は、文末に、この分野の本を載せました。

使いながら、欲しい機能を足していった

最初は、プロンプトを入れて画像が出るだけの画面でした。使ううちに、欲しくなったものを足していきました。

  • 簡易と高精度の切り替え。ラフに何枚も作りたいときは簡易、ここぞというときは高精度です
  • 参考画像モード。画像を渡して、デザインを変えてもらいます
  • ネガティブプロンプト。出したくない要素を指定できます
  • 日本語から英語への自動翻訳。日本語で書いても、英語のプロンプトに直して渡します
  • 変化量スライダー。頭、髪、目、口、顔、体、腕、脚、服、小物、色、素材。12の部位から、変える場所を選べます
  • セーフモードのオン/オフ。初期値はオフにしました
  • 残りニューロン数の表示。生成のたびに、使った分がわかります

とくに変化量スライダーは、思った以上に便利でした。同じキャラを土台にして、服だけ、色だけを変えたバリエーションが作れます。

作りながら思いました。欲しい機能を言葉にして伝えるだけで、画面が育っていくのは、かなり楽しいです。

ここからは、機能のうち、仕組みがわかると便利なものを、実際に動いているコードの抜粋と一緒に見ていきます。

# 2つのモデルを呼び分ける部分
Workerの中核は、モデルを呼ぶところです。実際に動かしているコードから、簡易と高精度の呼び出しだけを抜き出すと、次のような形です。

const P = "@" + "cf/";
const MODELS = {
 draft: P + "black-forest-labs/flux-1-schnell",
 quality: P + "black-forest-labs/flux-2-klein-9b",
};

// 簡易:プロンプトとステップ数を渡す
resp = await env["AI"].run(MODELS.draft, { prompt: full.slice(0, 2048), steps });

// 高精度:フォームデータにして渡す
const form = new FormData();
form.append("prompt", full);
form.append("width", String(w));
form.append("height", String(h));
form.append("seed", String(seed));
const fr = new Response(form);
resp = await env["AI"].run(MODELS.quality, {
 multipart: { body: fr.body, contentType: fr.headers.get("content-type") },
});

1行目の `@` を分けた書き方は、この記事の表記の都合です。貼れば、ひとつながりの名前として動きます。上のコードは、全体の一部を抜き出したものなので、これだけでは動きません。`full` や `steps` などは、ほかの部分で作っています。

見てほしいのは、呼び方が2通りあることです。簡易は、文字のプロンプトとステップ数を渡すだけ。高精度は、フォームデータの形で渡します。モデルごとに、受け付ける入力の形が違います。この違いが、あとで私をつまずかせました。

# プリセットとセーフモード
スタイルの指定は、プリセットとして、決まった英語の言い回しを足す形にしました。

  • cyber:サイバーパンクのスタイル、シアンとマゼンタの縁取りの光、暗い背景
  • anime:アニメ調、くっきりした線画、セル塗り
  • flat:フラットなイラスト、単純な形、限られた配色
  • photo:写真のようなリアルな質感

セーフモードをオンにしたときは、プロンプトの末尾に「仕事で使っても問題のない、服を着た、露出のない」という意味の英語を足し、ネガティブ側にも露出を避ける語を入れます。初期値はオフですが、画面のチェックひとつで、いつでもオンにできます。

# 日本語の自動翻訳
画像生成モデルは、英語のプロンプトのほうが意図どおりに出やすい傾向があります。でも、毎回英語で書くのは面倒です。そこで、日本語で書いたプロンプトを、テキスト用のモデルで英語に直してから、画像のモデルに渡すようにしました。

翻訳に使うのは、テスト編で選んだ `qwen3-30b-a3b-fp8` です。指示は、「日本語の画像の説明を、画像生成向けの簡潔な英語に直す。英語の文だけを出力する」という内容にしています。翻訳の分は、ニューロンの消費の見積もりに、1回あたり約70を足しています。この数字は、私の計算による目安です。

# 変化量スライダー
12の部位ごとに、「頭は、ヘルメットのような形」「髪は、長いツインテール」のような言い換えの候補を、5つ前後ずつ用意しておきます。スライダーは0から3までの4段階で、強さを上げるほど、変える部位が増えます。

  • 強さ1:12の部位から、ランダムに1つだけ選ぶ
  • 強さ2:ランダムに3つ選ぶ
  • 強さ3:ランダムに5つ選ぶ

選ばれた部位ごとに、候補の中から、これもランダムに1つを選び、生成のプロンプトの後ろに足します。つまり、生成のたびに「ランダムに何個か」の変更が加わる仕組みで、同じ指示でも、毎回ちがう変化が出ます。変えたくない部位は、チェックを外して対象から除けます。

参考画像と一緒に使うと、同じ雰囲気のまま、部位だけを変えた別案が作れます。強さ1は「同じキャラと同じポーズのまま、少しだけ」、強さ2は「同じポーズのまま、変える」、強さ3は「ポーズだけを残して、作り直す」という指示に変わります。

たとえば、服の候補には、次のようなものを入れています。

  • サイバー風の戦術ジャケット
  • 縁にネオンのラインが入った長いコート
  • 光る飾りのついたテックウェアのパーカー

候補は、自分の好みに合わせて、いつでも書き換えられます。

# 残りニューロン数の表示
生成のたびに、使ったニューロンの見積もりを足していき、画面に出します。この数字は、ブラウザの中に保存しているだけで、Cloudflareに問い合わせているわけではありません。あくまで見積もりで、実際の課金単位・使用量とは一致しない可能性があります。正確な利用量は、CloudflareのWorkers AIダッシュボードで確認します。このズレの話も、失敗とコスト編で書きました。

見積もりの式は、公開されている価格表をもとに、自分で組んだものです。簡易モード(schnell)なら、1回あたり「19.2 + 38.4 × ステップ数」。ステップ数4なら、約173になります。

図解は、このツールの仕事じゃない

使い分けも決めました。

  • サイバー系のキャラクターは、このツールで作る
  • 記事のワークフロー図は、ClaudeにMermaidやSVGで描いてもらう

図解を画像生成AIに任せると、文字が崩れたり、線がつながらなかったりします。図解はコードとして書かせたほうが、正確で直しも効きます。この記事の全体像の図も、コードで描いたものです。

得意な道具に、得意な仕事を。小さな分業ですが、これで以前よりずっと楽になりました。

無料枠を長持ちさせる使い方(筆者の考え)

【2026年11月9日追記】この構築で翻訳に使用した @cf/qwen/qwen3-30b-a3b-fp8 は、Cloudflare公式の11月5日付告知で11月20日の廃止予定に含まれています。記事の実験値は当時の記録です。今後の運用ではモデルIDの更新に加え、応答形式・課金単位・アプリの動作を検証する必要があります。

最後に、数字から考えた使い方を、2つだけ書いておきます。実際の消費量は、次の失敗とコスト編で詳しく書きます。

  • 簡易で方向を決めてから、高精度で仕上げる。簡易は1枚あたり約173ニューロン、高精度は約1,364ニューロンの見積もりで、差は約8倍です。最初から高精度で回すと、1日の無料枠が、あっという間に尽きます
  • 簡易は、同じ指示でも毎回違う絵が出る。気に入る1枚が出るまで、枚数で試せるのが、簡易の強みです

まとめ

  • 自分専用の画像生成ツールは、Claudeにコネクタをつなぐと、Workerの作成からデプロイまで、ほぼ自動で作れる

ClaudeやChatGPTを用いた、脆弱性の整理のしかた

夜、ニュースで「取引先を狙った不正アクセス」の話題が流れる。ふと、うちの会社のことが頭をよぎる。でも、何から確かめればいいのか分からない。IT担当に聞いても「たぶん大丈夫だと思います」としか返ってこない。

みなさん、セキュリティ、不安ですよね。実は、難しい道具を使わなくても、今日からできる簡単なチェックがあります。使うのは、ClaudeやChatGPTといった対話型のAIと、社内で確認した設定項目のメモです。管理画面のスクリーンショット自体は、原則として外部AIに渡しません。ITに詳しくない方でも進められるよう、順番に説明します。

この記事でわかること

  • 社長が自分でできるのは、攻撃テストではなく「設定の見直し」まで
  • 社内で設定を確認し、機密を含まない項目に整理してからAIに相談する
  • AIの答えは「今すぐ」だけ読めばよい。3か月ごとに、同じ手順でやり直す

「うちは大丈夫か」に、誰も答えてくれない理由

セキュリティの話が難しく感じられるのは、「何が危ないのか」が目に見えないからです。火事なら煙が出ます。泥棒なら鍵が壊れます。ところがネットの世界では、玄関の鍵が開いたままでも、誰かが入るまで気づけません。

しかも、社内の状況を一番知っているはずの担当者も、日々の対応で手一杯です。「問題は起きていない」ことと「安全である」ことは、同じではありません。ここが、不安の正体だと思います。

では、どうするか。まず、自分の目で現状を一度整理してみる。そのための道具として、AIが使えます。

# 先に、お断りをひとつ
この記事で紹介するのは、あくまで「設定の見直し」です。実際に攻撃を仕掛けて穴を探す、本格的な診断（脆弱性診断）の代わりにはなりません。

健康診断にたとえるなら、人間ドックの前に、自分で血圧を測ってみるようなものです。「測ってみたら高かった」と気づけるだけで、次の一手が決まります。反対に、測らないままでは、高いのか低いのかも分かりません。

手順1：まず「共通」と「足すもの」を確認する

オフィスには、ほとんどの場合、インターネットの出入口になるルーター（Wi-Fiの機器）があります。つまりルーターは、会社の種類に関係なく、全員が確認する項目です。

そのうえで、自社が持っているものを「足し算」していきます。足すものは、次の3つです。

  • 共通：ルーター、Wi-Fi、パソコンの台数
  • 足すもの①　クラウド：Microsoft 365やGoogleのサービスを使っている
  • 足すもの②　社内の機器：社内にサーバーやNAS（共有ハードディスク）、UTM（社内の出入口でウイルスや不正な通信を防ぐ機器）、VPN（自宅や出張先から社内につなぐ専用の入口）がある
  • 足すもの③　自社サイトや業務システム：ホームページや、お客様がログインする仕組みがある

当てはまるものは、複数あるかもしれません。ですが、全部を一度にやる必要はありません。「共通」と、足すものを1つだけ。続けやすさのほうが、網羅することよりも大切です。

迷ったときは、次の問いで決められます。

  1. 毎日使うメールや共有フォルダは、クラウドにありますか。あれば①
  2. 社内に、サーバーやNAS、UTM、VPNの機器がありますか。あれば②。VPNがあれば、次の「VPNの確認」を最優先にしてください
  3. ホームページや、お客様がログインする仕組みがありますか。あれば③

手順2：社内で設定項目と証拠を確認する

社内の担当者と一緒に管理画面や契約書を確認し、『確認できた項目・不明な項目』をメモします。必要な画面のスクリーンショットは社内の適切な保管場所だけに残し、外部AIへそのまま送らないでください。

確認してほしい項目を、「共通」と「足すもの」に分けて並べます。

# 全員共通

  • ルーターの設定画面。つなげている機器の一覧や、Wi-Fiの設定が分かる部分です
  • 社内のパソコンの一覧。Excelやメモ書きでも構いません
  • 社内のセキュリティに関するルール。なければ「なし」で構いません

# ①クラウドを使っている方

  • 管理画面の「ユーザー一覧」。誰がどの権限を持っているかが分かります
  • 「多要素認証（ログイン時にスマホで確認する仕組み）」の設定状況の画面
  • ファイルの「共有設定」の画面。社外の人にも見える状態になっていないかを確かめます

# ②社内に機器がある方

  • サーバーやNASの管理画面。誰がどのフォルダを見られるかの設定
  • UTMの設定画面（あれば）。次の3点が分かる画面を撮ります
  • 「ウイルス対策」「不正侵入の防止」といった機能が、オンになっているか
  • ライセンス（利用契約）の期限が、切れていないか
  • 機器の中のソフト（ファームウェア）が、最新に近い状態か
  • NASの共有フォルダの設定画面
  • 機器の名前と、導入した時期が分かる一覧

# ③自社サイトや業務システムがある方

  • 制作会社や保守業者からもらった報告書や、構成の説明資料
  • 契約書のうち、保守の範囲が書かれた部分
  • 管理画面にログインできる人の一覧
  • VPNの設定画面（あれば）。誰が使えるか、どんな方法でログインするかが分かる画面です。詳しくは、次の節で説明します

UTMがない会社も、心配は要りません。その場合は、ルーターの画面だけで始められます。UTMとルーターが一体になった機器もあるので、どちらか分からないときは、機器の型番を社内担当者や保守業者に確認してください。

管理画面の場所が分からないときは、遠慮せずにIT担当の方や、いつも頼んでいる業者さんに「この設定の確認結果を、機密情報を除いた一覧で教えてください」と頼んでください。この一言だけでも、立派な仕事になります。

ここで、ひとつ気づくことがあるかもしれません。「この画面、誰も見たことがない」「そもそも誰が管理しているのか分からない」。実は、それ自体が一番大きな発見です。

# VPNがある会社は、ここを最優先に
在宅勤務や出張先から社内のデータを見られるようにするために、VPNを使っている会社があります。便利な反面、外から社内に入れる入口でもあります。だからこそ、侵入を試みる側にとっても、いちばん狙いやすい場所になります。

実際に、警察庁がまとめた令和7年上半期の統計では、ランサムウェア（データを人質に身代金を要求する攻撃）の感染経路のうち、VPN機器からの侵入が最も多く、6割を超えていました。

VPNがある会社は、社内の管理者に次の3点を確認してください。

  • 誰が使えるか：VPNを使えるユーザーの一覧。退職した方や、使っていない方が残っていないか
  • どうログインしているか：パスワードだけか、スマホでの確認（多要素認証）もあるか
  • 機器のソフトは新しいか：VPN機器のファームウェア（機器の中のソフト）の版と、最後に更新した時期

とくに見てほしいのは、2点目と3点目です。パスワードだけで入れる状態、そして更新されないまま放置された機器は、狙われやすい典型です。もしVPNがあるのに、この画面を誰も見たことがなければ、その発見自体が、今日いちばんの収穫です。

手順3：AIに渡すのは、機密を含まない確認項目だけ

ここが、この手順で最も大切なところです。ルーター・UTM・VPN・Microsoft 365などの管理画面には、黒塗りしても構成や権限が読み取れる機微情報が残り得ます。外部のAIに管理画面の画像を送ることは、原則として避けてください。

社内のIT担当者か契約先の業者と一緒に画面を確認し、AIに相談するのは次のような抽象化したチェック項目だけにします。

  • 多要素認証を全員に適用できているか（はい／いいえ／未確認）
  • 退職者のアカウントを停止する手順があるか（はい／いいえ／未確認）
  • VPN機器の更新状況を定期的に確認しているか（はい／いいえ／未確認）
  • 社外共有の承認・点検ルールがあるか（はい／いいえ／未確認）

社内システム名、IPアドレス、利用者名、画面、契約書、内部構成図、鍵や認証情報は含めません。会社のAI利用ルールと契約を確認し、外部送信の可否は組織で判断してください。判断できない場合はAIに入力せず、社内の担当者に相談します。

重要：社外AIに実際の管理画面を送るのではなく、利用許可のある非機密のチェック項目を文章にして渡してください。黒塗りした画像にも、構成・利用者・設定の機微情報が残る可能性があります。

手順4：AIに頼む（コピペ用の文例）

いよいよ、AIに頼みます。ClaudeでもChatGPTでも構いません。社内で確認した非機密の項目だけを使い、次の文章の【　】を書き換えて相談してください。設定画面や内部資料は添付しません。

私は【業種：例）製造業】の会社を経営しています。従業員は【30】名ほどです。守りたいものは【お客様の情報と、請求書のデータ】です。
確認した結果は、【多要素認証：未確認／退職者IDの棚卸し：未確認／VPN機器の更新確認：実施済み】です。固有名詞やシステムの内部情報は含めていません。
ITに詳しくない経営者向けに、次の3つに分けて教えてください。
1. 今すぐ直すべきこと
2. 今月中に直すこと
3. 余裕があるときに直すこと
専門用語は使わず、使う場合は一言で説明してください。
また、担当者や業者に頼むときの依頼文も書いてください。

ポイントは、「業種」「人数」「守りたいもの」を伝えることです。同じ確認項目でも、業種や取り扱う情報によって、優先すべきことは違います。AIも、手がかりが多いほど、現実に合った答えを返せます。

# 答えがぼんやりしたら
最初の答えが一般的すぎると感じたら、次のように重ねて頼んでください。

  • 「いまの指摘を、費用がかからない順に並べ直してください」
  • 「担当者が1人しかいない会社でもできる範囲に絞ってください」
  • 「この指摘が正しいかどうか、確認する方法を教えてください」

3つめは、とくにおすすめです。AIの答えをそのまま信じるのではなく、確かめ方まで聞いておく。この癖がつくと、AIとの付き合いが安全になります。

手順5：結果は「今すぐ」だけ読む

AIの答えは、「今すぐ」「今月中」「余裕があるとき」の3つに分かれて返ってきます。

読むのは、「今すぐ」だけで十分です。全部を読んで全部を直そうとすると、続きません。

たとえば、「多要素認証が設定されていない人がいる」「退職した人のアカウントが残っている」「共有フォルダが社外にも見える設定になっている」といった指摘が出たとします。いずれも、セキュリティの基本として、よく挙げられる項目です。

指摘が出たら、AIが作ってくれた依頼文を、そのまま担当者や業者に渡してください。「社長が自分で設定を変える」必要はありません。社長の仕事は、見つけることと、頼むことです。

# 担当者や業者への、頼み方のコツ
指摘を渡すときは、責めるような言い方にならないよう気をつけてください。「AIがこう言っている。本当か確認してほしい」と伝えるのが、いちばん角が立ちません。

  • 「AIの指摘を、まず担当者の目で確認してほしい」と、確認から頼む
  • 直す期限は、「今すぐ」の項目だけ短く決める。たとえば1週間以内、のように
  • 直し終えたら、同じ設定の確認結果をもう一度、社内の担当者から報告してもらう

最後の「もう一度確認する」が、とても大切です。「直しました」という言葉だけでなく、担当者の点検記録で改善を確かめられるからです。社長は結果と対応日、残っているリスクを確認できます。

# つまずきやすいところ
実際にやってみると、次のような場面でつまずくことがあります。

  • 管理画面に入れない。 管理者の権限を持つ人が、退職していたり、分からなくなっていたりする場合です。これも、重要な発見として記録しておいてください
  • 画面が専門的すぎて、何を撮ればよいか分からない。 IT担当者や保守業者に、どの項目を確認すべきか聞いてください。画面自体は外部AIに送らないでください
  • AIの答えが長すぎて読めない。 「今すぐの項目だけを、3つ以内で」と頼み直してください

どれも、一度つまずいて終わりにせず、「何が分からなかったか」をメモしておくと、次にやり直すときに役立ちます。

# 3か月後に、もう一度やる
一度やって終わりにしないことも大切です。人の入れ替わりや機器の追加で、設定は少しずつ変わります。3か月に一度、社内で同じ項目を点検し、非機密の結果だけを必要に応じてAIに相談する。それだけで、「前回との違い」が見えてきます。

カレンダーに、あらかじめ予定を入れておくのがおすすめです。

注意：AIは万能ではありません

便利な道具ですが、限界もあります。次の3つは、必ず頭に置いてください。

  • 見落としがあります。 「問題は見当たりません」と言われても、「安全です」という意味ではありません
  • もっともらしい間違いも言います。 気になる指摘は、必ず担当者や専門家に確認してください
  • 調べてよいのは、自社の画面だけです。 許可のない他社の環境を調べると、法律に触れるおそれがあります

AIは、会社の中の事情までは知りません。画面に写っていないことは、判断できません。だからこそ、「業種」や「守りたいもの」を伝えることが効いてきます。

30日後の会社を、想像してみてください

ここまで読むと、「結局、何が変わるのか」と思われるかもしれません。そこで、仮の話をひとつ。たとえば、こんな1か月を想像してみてください。

  • 1日目：社内担当者にユーザー一覧を確認してもらい、退職者IDの管理状況だけを整理する
  • 3日目：社内の確認で、退職した方のアカウントが残っていると分かる
  • 1週間目：AIが作った依頼文を、そのまま担当者に渡す。「確認します」と返事がくる
  • 2週間目：担当者の作業記録で、当該アカウントが停止済みと分かる
  • 30日目：同じチェック項目を点検する。未対応の項目が、ひとつ減っている

社長は、設定を1つも触っていません。見つけて、頼んで、見比べた。それだけです。

それでも、会社の状態は確かに一段変わりました。「たぶん大丈夫」だったものが、「ここまでは確認した」に変わったのです。この差が、夜のニュースを見たときの気持ちを、静かに変えてくれます。

そして、「今すぐ」の項目がひとつ減ったときの、あの小さな手応え。それがあれば、3か月後のやり直しも、続けられるはずです。

まとめ

  • 社長ができるのは、攻撃テストではなく「設定の見直し」。それでも、現状を知る大きな一歩になる
  • 社内で設定を確認し、機密を含まない項目だけをAIに相談する。結果は担当者と検証し、3か月ごとに繰り返す
  • 迷ったら送らない。管理画面・構成・認証情報は社内で取り扱い、外部AIには非機密の確認事項だけを渡す
  • 冒頭の夜を、もう一度思い出してください。ニュースを見て、ふと会社のことが頭をよぎる。あのとき足りなかったのは、知識でも予算でもなく、「一度、画面を見たこと」でした。
  • 不安の正体は、分からないことです。そして、分からないことは、社内での一度の設定確認から、少しずつ分かることに変わります。

明日からの一歩

今夜、いちばん小さな行動をひとつだけ。会社のルーターか、Microsoft 365・Googleの管理設定について、担当者に『多要素認証・更新状況・権限』の3点を確認してもらってください。30日後の改善は、その確認から始まります。

そして、ここから先は、ひとりで抱え込まないでください。

「自社の設定を、もっと詳しく調べてほしい」「画面を見ても、何が危ないのか分からない」「どこから直せばいいのか、決めきれない」。そんなお困りごとがあれば、遠慮なく、ご用命ください。

詳細な調査も、お困りごとの整理も、承ります。小さな不安のうちに、声をかけてください。

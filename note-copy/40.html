連載「自動で株の売買を行う夢見る人」の第1回です。

「Claudeのクレジットが100ドルも余っているじゃないか」という、ひと握りの勢いで始まった話です。口座を開き、システムを作り、API申請の画面で、ある質問に不意打ちされて焦るまでを、ウィブル証券の画面の画像つきで、順番に書きました。

これから同じ道を歩く人は、私のつまずいた場所を、先回りして避けてください。

この記事でわかること

  • 自動で株の売買をする、とはどういうことか(概要)
  • 証券会社に、ウィブル証券を選んだ理由
  • 口座開設までの方法

100ドル残っていたので、再挑戦した

ある日、利用状況の画面を開くと、クラウドセッションのクレジットがまるごと残っていました。100ドル。期限は11月5日。

期限つきの残高ほど、人を急かすものはありません。

じつは以前にも、株の自動売買を考えたことがあります。机の上で成績を試算してみたところ、ETF(上場投資信託)を放っておくほうが強い、という身も蓋もない結果でした。それで一度やめていたのです。

ところが、100ドルあれば、システム一本分は作れそうでした。勝てるかどうかは、作ってから考えればいい。そう決めて、再挑戦です。

そして、最初のお約束を決めました。

  • 許可を出すまで、実際の売買はしない
  • 総資産が最初の資金から20%減ったら、全停止する
  • まずは、仮想のお金を使った疑似売買(シミュレーション)で試す

夢を見るのは自由ですが、財布まで夢の中に置いてはいけません。

自動で株の売買をする、とはどういうことか

最初に、私が作ろうとしているものを、ざっくり説明します。

自動売買といっても、魔法ではありません。やることは、人が毎日やっていることの置き換えです。

  1. 決まった間隔で、株価を見にいく
  2. 自分で決めたルールに当てはめて、買うか、売るか、何もしないかを決める
  3. 決まったら、証券会社に注文を出す

この三つを、プログラムが人の代わりに繰り返す。それだけです。

私の場合は、対象を米国株だけに絞りました。株価を見にいくのは、1時間に一度です。売った分は、円に戻さず、ドルのまま持っておきます。

そして、大事なのがこれです。私が許可を出すまで、本物の注文は出さない。最初は、本物の相場データと仮想のお金で、売買の「ふり」をさせます。うまくいくかどうかは、そこで見ます。

許可を出したあとは、1件ごとに私が承認することはありません。プログラムが、自分の判断で勝手に売り買いします。自動売買ですから。

「ルールを決める」ところが、この連載のいちばん大事な部分ですが、中身は公開しません。代わりに、そこへたどり着くまでの道のりを、全部書きます。

証券会社に、ウィブル証券を選んだ理由

プログラムが注文を出すには、証券会社の側に、プログラムの入口が要ります。それがAPIです。人がアプリの画面を押す代わりに、プログラムが決まった形で「この株を買います」と伝えられる窓口のことです。

私の用途は、「米国株の相場をプログラムで受け取り、プログラムから注文を出す」ことでした。

もう一社条件に合う証券会社がありましたが評判が悪そうなので、ウィブル証券を選びました。評判はご自身で検索を！

  • 日本の個人向けに、OpenAPIという公式の窓口が用意されている
  • 米国株を扱っていて、公式のPython用の道具(SDK)が使える
  • 相場データの一部(Nasdaq Basic)が、無料で受け取れる

どれも、あとで実際に触って確かめた点です。無料で受け取れる相場データについては、あとの章で画面を出します。

まず口座を開いて、入金した

APIを使うには、まず口座が要ります。ウィブル証券の口座を開くところから始めました。

入口は、ウィブル証券の「はじめての方へ」のページです。

口座開設の手順や必要な書類は、ウィブル証券の公式サイトにある「はじめての方へ」の案内で確認できます。申込時は最新の画面表示と条件に従ってください。

口座開設は、むずかしくありません。ボタンを押して、画面の案内どおりに進めていけば、できます。

ページの「口座開設」のボタンを押して進めると、新規登録の画面が出ました。

携帯電話の番号を入れて、利用規約に同意のチェックを入れ、「確認コードを送信」を押します。届いたコードを入れたら、あとは本人確認など、画面に出てくる案内に沿って、次へ、次へと進めるだけです。私も、迷ったところはありませんでした。

口座ができたら、入金です。

ここで、ここだけの話をひとつ。

最初は、10万円を入れるつもりでした。ところが、入金の画面を前にして、ふと財布と相談したところ、「5万円にしておきなさい」という声が聞こえたのです。誰の声かは言いません。

というわけで、資金は5万円になりました。全停止のラインが「総資産の20%減」、つまり4万円なのは、そのためです。10万円のままなら、ラインは8万円で、もっと強気な数字だったはずです。

※停止条件は筆者が本文で説明した設計上のルールです。実装がこの条件に一致するかは、注文を有効化する前にコードと実行ログで確認する必要があります。

作り終えたら、30ドルほど残っていた

口座に入金を済ませたあと、システムの設計と作成に入りました。

どこで何を見て、どう判断するのか。判断の中身は、この連載では書きません。売買の核になる部分は、公開しないと決めているためです。

そして、一通り作り終えたところで、利用状況を見ました。

残りは、30ドルほど。100ドルあった余裕が、ずいぶん減っています。けれど、システムは動く形になりました。あとは、ウィブル証券のAPIを使う申請をするだけです。気分は、もう半分ゴールでした。

全体の流れは、公式の案内で6段階に分かれています。

  1. 証券口座の開設
  2. OpenAPIの利用申請と規約同意
  3. 審査
  4. OpenAPIの利用登録
  5. API Keyの生成
  6. 利用開始

口座開設は済んでいるので、次は2番目です。

申請書の「クオンツ?!」で手が止まった

申請の画面には、いくつか質問が並んでいました。開発は自分でするか、プログラミングの経験は何年か。そのあたりは、すらすら答えられます。

そして、その中の一つに、こんな質問がありました。

「クオンツ・トレーディング／プログラム・トレーディングの経験は何年ですか?」

……えっ?!

聞き慣れない言葉が二つ並んでいます。プログラミング歴は長いのに、この欄だけ手が止まりました。焦って、調べ直しです。

# クオンツ・トレーディングとは

調べてみると、こういう投資手法でした。

数学・統計学・プログラミングを使い、データにもとづいて売買の判断を行う方法。

もう少し噛み砕きます。

ふつうの株取引は、「この会社は伸びそう」「ニュースが出たから買おう」と、人が感覚や情報で決めます。クオンツは、それを数字に置き換えます。「過去のこういう値動きのあとは、こう動くことが多かった」といった傾向を、統計で確かめ、ルールにするのです。

ルールが決まれば、あとは機械に任せられます。感情が入らないのが、強みです。

ちなみに「クオンツ」は、数量を意味する英語に由来する呼び名です。数字で考える人たち、というくらいの意味だと思ってください。

# プログラム・トレーディングとは

こちらは、決めたルールをプログラムが自動で実行する取引のことです。

クオンツが「どう判断するか」の話なら、プログラム・トレーディングは「どう実行するか」の話。判断を人がしていても、注文だけ機械が出せば、プログラム・トレーディングに近づきます。

この二つを合わせたものが、私がこれから動かそうとしているものでした。つまり、私の自動売買は、まさにこの質問が聞いている中身そのものだったのです。

# 答えは「0〜1年」

さて、経験は何年か。

正直に答えるしかありません。仕事でのプログラミングは長くても、売買を機械に任せた経験は、これが最初です。選んだのは「0-1年」でした。

ここは見栄を張らないほうがいい、と思います。申請の内容は、あとで見返されるものです。盛った経験年数で通っても、使い始めてから苦しくなるだけです。

ほかの質問も、同じです。設計に入っていないと答えにくい質問が、ほかにも並んでいます。作り終えたあとに聞かれると、こういう質問は心臓に悪いのでした。

「ほぼ入っています」と言われた設計

質問に答えながら、もう一つ気になりました。最初に自分で決めたルールが、できあがったシステムにきちんと入っているのか。

そこで、ルールを一つずつ並べて、設計と照らし合わせてもらいました。

  • 許可するまで売買しない
  • 資金は5万円
  • 総資産が20%減ったら(4万円を切ったら)全停止
  • まずは疑似売買で試す

返ってきた答えは、「ほぼ入っています」。

ほぼ。

この二文字が、ちょっと怖いのです。「ほぼ」のすき間は、たいてい財布のほうへ流れていきます。

実際、手直しが必要な箇所が、いくつか見つかりました。どれも、動かす前に見つかって良かったものばかりです。中身は、ここでは書きません。

そして、直してもらいました。ほかのリポジトリ(別の作りかけ)も、ついでに手直ししています。そのぶん、クレジットは減りました。

残りは、16ドル。

100ドルあった余裕が、30ドルになり、最後は16ドル。期限つきの100ドルは、ちゃんと仕事をしてくれました。

承認が出て、アプリを登録した

申請を送ると、審査が始まります。私の場合は、10月27日に申請して、翌28日に承認されました。日数は目安です。承認されると、この画面が出ます。

「APIの利用登録を行なってください」と案内が出たら、次へ進めます。最初は、登録済みのアプリが何もない状態です。

「アプリの登録」を押して、必要な項目を入れます。

気をつけたい点を、並べておきます。

  • アプリ名に、記号は使えません。私は最初に記号を入れようとして、はじかれました。英数字だけにすると通ります
  • API利用権限は、「マーケットデータ」と「取引ツール」を選べます
  • ホワイトリストのアドレス帯は、接続元を絞りたい人向けの設定です
  • 2段階認証は、オンのままにしておくのが安心です

ここで一つ、大事な話です。「取引ツール」の権限を付けると、注文を出せる鍵ができます。

疑似売買だけの段階なら、最初は「マーケットデータ」だけにしておく手もあります。取引ツールは、必要になってから足せますし、登録のあとに「修正」で変えられます。私も、疑似売買の期間は外すことを考えています。

登録が終わると、一覧に表示されます。

右側の操作欄には、「詳細」「修正」「Keyの生成」「削除」が並びます。画面の下には、「リアルタイムのマーケットデータを使うには、非表示利用の申込みが必要です」という案内も出ています。この話は、あとで書きます。

鍵を作る。ただし、絶対に貼らない

一覧の「Keyの生成」を押して、キーを作ります。ここは、慎重にしてください。

  • 生成されたキーとシークレットは、その場で安全な場所に控える(あとから見直せない項目があります)
  • 画面の画像・チャット・メモ帳に、そのまま貼らない
  • プログラムから使うなら、ソースコードに書かず、環境変数や、GitHubのSecrets機能に入れる

私は、GitHubのSecrets機能に入れました。名前は、キーとシークレットで別々に付けています。

そして、このキーは人に教えない。サポートの人にも、です。

相場データを使うまでが、意外と長い

さて、鍵があっても、まだ終わりではありません。APIでリアルタイムの株価を受け取るには、「非表示利用」の申込みが必要です。ここが、いちばんつまずきやすいところでした。

私の画面で通った順に、書いていきます。

# まず、購読区分に答える

最初に、「購読区分」の確認が出ます。あなたが「個人の利用者」か、「プロとしての利用者」かを分けるための質問です。

ここは、正直に答えてください。画面にも書いてありますが、一般ユーザーと誤って申告すると、あとからプロの料金をさかのぼって請求される可能性があります。

私は個人として、自分のお金で使うので、その前提で答えました。ただし、あなたの状況で答えが変わる質問です。迷ったら、ウィブル証券のサポートに聞いてください。

答え終えたら、「提供した情報が正確である」という確認にチェックを入れて、保存します。

# 次に、本人確認をする

保存すると、本人確認の画面が出ます。

登録の電話番号にSMSで届く認証コードと、取引パスワードを入れます。「認証コード送信」を押して、届いたコードを入力してください。

私の画面では、この流れで出ましたが、出るタイミングは、操作の順番で前後するかもしれません。画面の案内どおりに進めてください。

# 「Open API Quotes に切り替え」を押す

ここが、いちばん大事なボタンです。

相場情報の設定ページを開くと、最初は「端末用リアルタイム相場情報」という見出しになっています。

この見出しの右側に、「Open API Quotes に切り替え」というボタンがあります。これを押さないと、APIでマーケットデータを受け取れません。私は最初、これを見落とすところでした。

# 商品を選んで、無料で取得する

切り替えると、APIで使える相場情報の商品が並びます。

私が見た時点では、次の通りでした。

  • Nasdaq Basic - Non Display: 無料
  • Nasdaq Totalview - Non Display: 月135ドル
  • Overnight Consolidated Level 2 - Non Display: 月20ドル
  • OPRA Real-Time Non-display: 月4.99ドル
  • Order Flow Non-display: 月16.99ドル

価格は、一般ユーザー向けのもので、予告なく変わることがあります。購読の前に、必ず画面で確認してください。まず試すだけなら、無料のNasdaq Basicで十分です。私もこれにしました。

商品の「申込み」を押すと、最後の確認画面です。

「マーケットデータの非表示利用に関する確認書」を読んで、同意にチェックを入れ、「無料で取得」を押します。

これで、相場データの設定は完了です。あとは、キーを使ってプログラムから接続するだけ。接続の方法は、ウィブル証券の公式の資料に従ってください。

# ここでつまずいた、五つのメモ

  • アプリ名に記号は入れられない。英数字で
  • 「Open API Quotes に切り替え」を押さないと、APIでデータが取れない
  • 購読区分は、正直に。プロ料金のさかのぼり請求を避けるため
  • キーとシークレットは、画面の画像やチャットに貼らない
  • 取引ツールの権限は、必要になってから付けてもよい

まとめ

  • 期限つきの余りクレジットは、再挑戦のきっかけとしては悪くない。ただし、100ドルが30ドル、16ドルと減っていく速さは、思ったより早い。そして、いちばんの山場は、購読区分への正直な回答と、「Open API Quotes に切り替え」の1回
  • 申請の質問は、設計を始める前に読んでおくと慌てない。「作り終えたあとにクオンツ?!」は、心臓に悪い
  • さて、あなたが自動売買を作るなら、最初に決めておくルールは何ですか? 私は、「許可するまで本番で売買しない」と「最初の資金から20%減ったら停止（今回は5万円から4万円まで下がったら全停止）」でした

次回予告

次回は、水曜から金曜までの疑似売買の記録です。本物の相場データと、仮想のお金で、自動売買が1時間おきに何を見て、何を判断したのか。そして、金曜日の結果は、ETFに勝てたのか、それとも……。

実際のお金を動かすのは、まだ先の話です。許可を出すまで、絶対に売買はしません。

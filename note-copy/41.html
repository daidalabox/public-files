連載「自動で株の売買を行う夢見る人」の第2回です。

ちょっと聞いてください。最新のAIと一緒に、あんなに頑張って作ったんですよ。 なのに、仮想の5万円は、爆上がりどころか、ほとんど動かないんです。

なんでだ？ 最新のAIで作ったんだから、勝手にお金が増えていくんじゃないのか？ 夢を見ていた私に、現実はそっと、小さな数字を返してきました。

この回では、水曜から月曜までの疑似売買の記録と、「短期で勝負するか、長期でじっくり持つか」で悩み抜いた話を、カッコ悪いところも含めて、ぜんぶ書きます。

この記事でわかること

  • 最新のAIで作ったのに、なぜ株価が爆上がりしないのか(正直な気持ち)
  • テクニカルとファンダメンタル、短期か長期か。机上で悩んだこと
  • 疑似売買の記録と、小さな資金で見つかった三つの落とし穴

最新のAIで作ったのに、なぜ爆上がりしないんだ

前回の最後に、「金曜日の結果は、ETFに勝てたのか、それとも……」と書きました。答え合わせの時間です。

結論から言うと、ETFと勝負できる段階には、まだ全然いません。 仮想の5万円は、数日でほとんど増えも減りもしませんでした。

正直に言います。ちょっと、期待していました。

だって、設計から作成まで、最新のAIと一緒にやったんです。1時間おきに自分で起きて、相場を見て、ルールに当てはめて、判断して、理由まで記録する。ここまで作り込んだシステムが、ドーンと資産を増やしてくれる。そんな絵を、頭のどこかで描いていたんですよね。

現実は、プラス0.08パーセントとか、マイナス3.67パーセントとか。自動販売機のお釣りみたいな数字です。

でも、冷静になって考えると、これは当たり前の話でもあります。AIがどれだけ賢くても、相場の「正解」を知っているわけじゃない。賢い道具を手に入れたことと、勝てることは、別の話なんです。

つまり、爆上がりの鍵は、AIの賢さの前に、「何を、どういう考えで売り買いするか」を決める人間側にある。ここがいちばん悩むところでした。

テクニカルとファンダメンタル、ざっくり説明します

悩みの中身を話す前に、二つの言葉を、かんたんに説明しますね。株の売買の判断には、大きく分けて二つの考え方があります。

# テクニカル：値動きを見る

株価のグラフの動きだけを見て、判断する方法です。「最近ぐんぐん上がっているから、勢いがありそう」「下がり続けているから、いったん手を出さない」といった具合。

たとえるなら、天気図を見て、傘を持っていくかを決めるようなものです。空模様(値動き)だけを見て、その会社の中身は、あまり気にしません。

# ファンダメンタル：会社の中身を見る

こちらは、会社の「体力」を見て判断する方法です。売上は伸びているか、ちゃんと利益が出ているか、借金が多すぎないか。決算書に載っている数字を使います。

たとえるなら、健康診断の結果を見て、選手を選ぶようなもの。今日の天気がどうであれ、体力のある選手に、長く期待するわけです。

# 短期と長期は、だいたいこう結びつく

  • 短期の売買は、値動き(テクニカル)と相性がいい。数日で売り買いを終えるので、チャンスの回数が多い
  • 長期の保有は、会社の中身(ファンダメンタル)と相性がいい。数か月じっくり持つので、売買の回数は少ない

どっちが正しい、という話じゃありません。でも、私のシステムには、どちらかを選ぶ必要がありました。

机上のシミュレーションで、ずいぶん悩んだ

本物の相場を動かす前に、過去のデータを使った、机上のシミュレーションをしました。ここで私は、本気で悩みました。

# 短期でちょこちょこ勝負する案

数日で売り買いを終える、短期型です。チャンスは多いし、結果もすぐ出る。毎日ワクワクできそうです。

ただ、試してみると、悩ましいことが分かりました。手数料や売買の細かい前提を少し変えるだけで、成績のプラスとマイナスが入れ替わるんです。勝てているのか、たまたまなのか、よく分からない。優位なところが、見つかりませんでした。

実際に、過去のデータを流して計算した結果を、ざっくり並べます。2019年から2026年まで、700銘柄超の時間足を使い、片道の費用を約0.055%(スリッページ込み)として処理しました。

  • 逆張り、高値の突破、勢いに乗る、値動きの小さい銘柄、月替わりの癖、よくある指標の組み合わせ。費用を引くと、どれも「勝てる」と言える形にはなりませんでした。
  • 高値の突破と勢いに乗る型は、むしろ平均より有意に悪いという結果でした(統計の目安で、マイナス2〜4)。
  • 唯一、少し気になったのが、急に跳ね上がった銘柄をその日のうちに売る型です。1回あたりプラス0.2〜0.4%、統計の目安でも2.6〜2.8まで出ました。ただし、費用を引く前の数字で、年を追うごとに縮んでいました。「見つけた！」と喜ぶには、まだ早い結果です。
  • AI関連の銘柄を集めたバスケットは、期間でプラス71%でした。けれど、同じ銘柄の中でランダムに売買した場合のほうが、成績は良かった。効いていたのは「銘柄選び」で、売買のやり方ではなかったんです。

さらに、いま上がっている銘柄に合わせて、ルールを調整する実験もしました。調整した期間では、見事に良くなります。ところが、別の銘柄や別の期間に当てはめると、その良さはスッと消えました。答えの決まっている問題に、答えを合わせただけだったんです。ガクッときました。

# 長期でじっくり持つ案

もう一つは、数か月単位で、会社の中身も見ながら持ち続ける型です。こちらは、強い上昇相場では、よく勝ちました。「勢いのあるものを持ち続ける」ほうが、過去のデータでは見込みがあったんです。

過去のデータで流すと、こんな結果でした。資金は、いまの5万円と同じ規模(333ドル)。市場全体を持ち続けた場合が、2020年からの同じ期間でプラス150%。それに対して、この型は、選ぶ対象を広げるほど数字が伸び、全銘柄から10銘柄持つ設定でプラス534%、2銘柄に絞る設定でプラス687%まで行きました。

数字だけ見れば、胸が躍ります。

けれど、これもいいことばかりではありません。下がっている時期や、横ばいの時期は、市場全体に勝てませんでした。2022年までの学習期間は、プラス12%どまり。2銘柄の設定では、最大の下落がマイナス47%、資金が一時222ドルまで減る場面もありました。開始時期をずらして1年ごとに見ると、23回のうち7回が損で、最悪はマイナス23%、真ん中の値でプラス47%。待つのは、けっこうしんどい。しかも、成績の大半は、ここ数年の上昇相場から来ていて、「たまたま追い風だっただけ」かもしれないという疑いが、消えませんでした。

# で、どうしたか

悩みに悩んで、私は、水曜から金曜のあいだに、短期型から長期型へ、ルールを入れ替えました。

ただ、これが正解かどうかは、正直、まだ分かりません。悩んだ末の、いまのところの答え、です。

水曜から月曜、何が起きたか

では、記録を順番に見ていきましょう。

# 水曜：最初の注文が入った

本物の相場データと、仮想のお金333.33ドル(日本円で5万円ぶん)。注文を出す窓口にはつながず、相場を受け取るだけの形です。第1回の「許可するまで売買しない」は、ちゃんと守っています。

初日、システムは2銘柄を買いました。1銘柄目は3株で約163ドルぶん、2銘柄目は1株で約75ドルぶん。引け後の総資産は332.28ドルで、マイナス0.32パーセントでした。

この記録を見直したら、ん？ と思うところが三つあったんです。

# 小さな資金だから見つかった、三つの落とし穴

大きな資金なら気にならないことも、333ドルだと、びっくりするほど目立ちます。

一つ目は、2銘柄目の配分が、なぜか半分だったこと。 2銘柄に、同じ金額ずつ分けるつもりが、1銘柄目は約163ドル、2銘柄目は約75ドル。計算が「残りの資金を残りの枠数で割る」形になっていて、2銘柄目が小さくなっていました。私は「半分にして」なんて頼んでいません。頼んでいないことをやるのが、機械の怖いところです。 全銘柄で同じ金額になるよう直しました。

二つ目は、2文字の銘柄記号が「オン」に化けたこと。 設定ファイルの世界では、その2文字が「オン(真)」という意味の言葉と同じ綴りで、銘柄の記号として読まれず、一覧から静かに消えていました。見つけられたのは、失敗の一行を記録に残していたから。判断の理由を全部書き出す仕組みにして、本当によかったです。

三つ目は、手数料の見積りが高すぎたこと。 私の口座の条件では、手数料はほぼ無料に近いのに、試算は高めでした。安全側に倒しすぎると、使えるルールまで「勝てない」と判定してしまいます。実際に近い値に直しました。

三つとも、派手に壊れたわけじゃありません。静かに、ちょっとだけ、おかしい。 小さな資金で試す意味は、まさにここにあるんですよね。

# 木曜：買えたのは1銘柄だけ

直したら、記録を空に戻して、仮想の333.33ドルから、やり直しました。買えたのは1銘柄だけ、15株で約78ドルぶん。引け後は333.60ドル、プラス0.08パーセントでした。

もう一つ、資金が小さいことの現実がありました。1株が高い銘柄は、そもそも買えないんです。水曜の引け時点の監視リストでは、買いの条件に合う190銘柄のうち、166ドルの配分で1株でも買えるのは、たった77銘柄でした。

「買いたい株」じゃなくて「買える株」から選ぶ。財布の大きさが、銘柄を決めてしまうんです。

# 金曜：システムは「買わない」を選んだ

ルールを切り替えた初日は、日本時間の金曜の夜。前日の引けのデータから、母集団350銘柄ほどのうち、条件に当てはまった26銘柄で、上位2銘柄に買いの予約が入りました。

ところが、注文を出す直前に、システムは予約を二つとも取り消しました。 現在値が、前日の終値より大きく下がっていた(2銘柄とも6〜7パーセントほど)ので、この日は買わない、と。

総資産は333.33ドルのまま。1セントも動きませんでした。

正直、ちょっとがっかりしました。切り替え初日から「買えた！」と喜びたかったんです。でも冷静に考えたら、買わなかったおかげで、金曜の損失はゼロ。「待て」と言ってくれた機械に、ちょっと感謝です。

# 月曜：買った途端に下がった

週明けの月曜(11月2日)の朝、システムはあらためて買いました。約163ドルと約152ドルぶん。

引けの結果は、1銘柄目が買値から約6.1パーセント下落、2銘柄目が約1.5パーセント下落。総資産は321.09ドル、スタートから12.24ドル減って、マイナス3.67パーセント。

いやー、なかなかのスタートです。この下落の原因は、私には分かりません。 1日では、判断が間違いだったのかどうかも分かりません。このルールは、短い値動きで一喜一憂しない作りなので、売りの条件に当たらないかぎり、システムは持ち続けます。

数字を、信じすぎちゃいけない理由

過去のデータでの検証には、気をつけている限界があります。

一つ目は、「勝った会社」ばかり選んでしまう問題。 いま人気の大きな会社を中心に試すと、あとから値上がりした銘柄が、最初から混ざってしまいます。生存者バイアスといいます。売買代金の大きい順に絞って試すと、成績は大きく縮みました。

二つ目は、成績の大半が、ここ数年の上昇相場から来ていること。 2023年以降の、AI関連が引っぱった相場です。2020年から2022年は、ほぼ横ばいかマイナス。2022年だけ見ると、マイナス19パーセントでした。

三つ目は、取引の回数が少ないこと。 設定ごとの取引は10回から25回ほど。数回の当たり外れで、結果が動きます。開始時期をずらして1年ずつ試すと、23回のうち7回が損で、いちばん悪いときはマイナス23パーセントでした。

さらに、本物のシステムそのものを、約700銘柄の過去の1年ずつ、何通りもの設定で回し直したところ、設定を少し変えただけで、1年の成績がマイナス42パーセントからプラス72パーセントまで動きました。 どの設定が最強かは、確定できませんでした。

だから、こう考えています。検証の結果は、データの取り方と前提を揃えて初めて比べられるもので、「このルールは勝てる」という証拠じゃなくて、「明らかにダメなものを外す」ための材料。 本物のお金を動かすのは、まだ先です。

それでも、動かしてよかった

ここまで読むと、「結局、何も分からなかったじゃん」と思われそうですよね。私も、半分はそう思っています。

でも、動かしてよかったことは、ちゃんとあります。

  • 静かなミスを、記録のおかげで三つも見つけられた
  • ルールを入れ替えた理由が、日付つきで、あとから読み返せる
  • 「買わない」日にも、なぜ買わなかったかが残る

勝ち負けより先に手に入ったのは、「自分のシステムが、何をやっているか分かる」という安心感でした。これがないまま本番に進んでいたら、静かなミスが、静かにお金を減らしていたかもしれません。

  • 短期のテクニカルか、長期のファンダメンタルか。机上で悩んで、いまは長期型を選んだ。でも、これが正解かは、まだ分からない

次回予告

というわけで、爆上がりには、まだ遠いです。でも、あきらめるつもりは、まったくありません。

まだまだ、爆上げまで、チューニングします。 次回は、ルールを変えたあとの続きをお伝えします。買った銘柄は持ち続けられたのか、それとも売りの条件に当たったのか。
